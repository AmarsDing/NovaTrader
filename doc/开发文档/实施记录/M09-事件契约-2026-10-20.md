# M09 事件契约：trade 域发布面（2026-10-20）

> 定位：trade 服务 NATS 发布面的集中合同书。逐字段以代码为准：`backend/pkg/events/envelope.go`（主题与信封）、`backend/app/trade/internal/biz/engine.go`（order/fill/reconciliation 载荷）、`core/runner.go`（channel 事件）、`data/repo.go`（派发链路）。
> 核销结论：核查报告《总体进度核查与实施计划-2026-10-20》§2.5 所记「M09 未发布 trade.account/order 事件契约」为**高估口径**——order / fill / account / reconciliation 早已随账本事务经 outbox 原子落库并派发，risk / strategy / notify / admin 四服务已在消费。真实未落地缺口是 M08 全链路演练与 LIVE 出口（第 3/4 波），不是发布动作。本文把分散合同收拢成单页，供消费方与验收直接引用。

## 1. 信封与派发纪律

- 信封：`events.Envelope` schema_version=1（event_id / trace_id / causation_id / source / subject / payload / time…）。消费端按 `event_id` 去重；`Unmarshal` 缺 event_id 直接拒绝。
- 生产者：仅 trade 服务，信封 `source` 恒为 `"trade"`。消费方必须同时校验信封 source/subject 与 NATS transport 主题（risk 生命周期测试矩阵八用例钉死冒名/缺账户/大小写变体全拒）。
- 原子性：order / fill / account / reconciliation 事件随 `biz.Batch.Events` 与账本变更写入同一 PG 事务（`data.Repo.Commit` → outbox 表），`pkg/outbox.Dispatcher` 后台派发；派发失败保留 outbox 行，进程重启不漏发。
- 因果：data 层一律 `events.NewWithContext`（上游 trace 透传、有真实父才编 causation_id）；通道状态事件从 Tracker 回调单独开根链（`OpenTrace` 幂等、不编 causation_id、5s 发送上限）。
- 持久性：`Persistent()` 除 `market.*` 与 `brain.progress` 外全真 —— trade.> 全域走 JetStream（`StreamSubjects` 含 `trade.>`）。

## 2. 主题与载荷

| 主题 | 时机 | 载荷键 | 出处 |
|---|---|---|---|
| `trade.order` | 委托提交/确认/撤单/追单/拒绝/风控退场等每一笔状态变化 | `client_order_id` `book` `symbol` `side` `status` `price` `volume` `filled` `reason` `signal_id` `strategy_version`（全小写 map） | engine.go `orderPayload` |
| `trade.fill` | 每笔真实撮合成交 | **PascalCase Go 结构键**：`ClientOrderID` `Book` `Symbol` `Side` `Qty` `Price` `Amount` `Fee` `SignalID` `StrategyVersion` `CreatedAt`（biz.Fill 无 json tag 的原样序列化） | engine.go:344-351 |
| `trade.account` | 完整 AccountSnapshotV1 成功提交才发；对账差异不发本主题 | `pkg/accountstate.Snapshot` 完整 state（现金/冻结/可卖/在途/日初/代际/对账），合同见 N0-01 实施记录 | repo.go / 设计文档 §9 |

| `trade.channel.status` | 执行通道状态迁移 idle→connected→degraded→down，G7 留痕 | `channel`（sim/emfile）`from` `to` `at`（RFC3339 UTC） | runner.go `publishChannel`（750bc71） |

## 4. 幂等与恢复

- 消费端去重 = `Envelope.EventID` + 各消费者 durable/投影位（strategy 投影重投保原链号，execution_nats_test 钉死）。
- 生产幂等 = outbox 同事务 + 派发重投；跨实例原子 claim 与持久执行意图见 N7 合同。
- 账本/快照恢复供 risk 启动（M08 新合同：以完整 AccountSnapshotV1 为准，旧摘要列不供恢复）。
