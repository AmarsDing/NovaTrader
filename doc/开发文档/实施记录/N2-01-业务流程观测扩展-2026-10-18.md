# N2-01 业务流程观测扩展（2026-10-18）

在[消费者与环境观测](N2-01-消费者与环境观测-2026-10-18.md)的固定合同与窗口基础上，继续接真实业务调用。注册代码不代表常驻服务已部署或业务ready；admin仍按实际HTTP结果分类。

## 已实现并定向核验

| 服务 | 固定操作 | 完成口径 |
|---|---|---|
| risk | account_restore/account_consume/config_reload/outbox | 启动恢复、完整快照处理、实际配置加载及投递轮次返回；不代表券商在线、订单批准或broker ACK |
| notify | recover/message_handle/held_flush | 实际Pipeline处理返回；包括持久化后的渠道失败，具体结果保留原通知记录，不代表用户收到/已读 |
| brain | analyze/briefing/explain/ask/outbox | biz真实结果保存返回；规则降级skipped、输出丢弃rejected、输入错误rejected、实际错误failed/cancelled，不代表预测准确或收益 |

沿用编译期固定标签、60秒桶、在途、幂等结算、P95直方图上界、未知分位数与实例重启边界；不引入证券/trace/正文标签。所有新增服务在原HTTP server登记生成的`/internal/observability`，由既有认证admin聚合，不开放客户端选址。

桌面增加跳过计数，区分开始/成功返回/失败/拒绝/取消/跳过；补全操作和完成范围中文说明。实际指标不支持时保留未知。

## 实际验证

在backend执行并通过：

```powershell
go test -race ./pkg/observe ./app/risk/internal/core ./app/risk/internal/server ./app/notify/internal/core ./app/notify/internal/biz ./app/notify/internal/server -count=1
go vet ./pkg/observe ./app/risk/internal/core ./app/risk/internal/server ./app/notify/internal/core ./app/notify/internal/server
go test -race ./pkg/observe ./app/brain/internal/biz ./app/brain/internal/core ./app/brain/internal/server ./app/admin/internal/gateway -count=1
go vet ./pkg/observe ./app/brain/internal/biz ./app/brain/internal/core ./app/brain/internal/server ./app/admin/internal/gateway
go build -o runtime/brain-check.exe ./app/brain/cmd
```

新增实际业务合同覆盖：错来源/缺字段账户不能成功；真实Pipeline两假渠道失败仍保存失败记录，数据库失败与坏信封分别计数；真实Analyze规则降级/两次非法输出/正常输出/坏参数四条路径；每一编译注册服务的生成HTTP闭集校验。测试不连接真实通知渠道或外部模型。

trade/backtest扩展正在独立合并，最终范围及验证会追加。未做全常驻环境、跨主机时钟、broker确认、全机资源和5000证券多窗口长时验收；不能据此宣布全链路健康。

## 兼容与停用

无schema或业务状态改动；观察HTTP与原业务ready分开，不修改交易门禁。旧二进制未登记端点时仍返回unsupported；部署新二进制后才获得新增指标。停止观测面板轮询不影响业务和风控。
