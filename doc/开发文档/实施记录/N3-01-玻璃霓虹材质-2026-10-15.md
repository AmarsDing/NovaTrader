保留监控画布/HUD/终端带、节点偏移与缩放，以及 dockview 一张票的现有结构。沿用深海暗色与红涨绿跌语义，增加以下材质层：

| 位置 | 已落地内容 |
|---|---|
| 统一令牌 | glass-bg/raised/border/highlight/sheen-color/blur/filter，data-bg/raised/inset，edge-light，glow-soft/active，space/grid/track；颜色仍由 tokens.css 单源提供 |
| 工作台 | 静态青蓝空间底、玻璃顶栏/底栏、菜单壳、活动标签光轨；面板宿主高不透明数据底，不给每张业务卡叠加 blur |
| 一张票 | 原票头玻璃反光与侧轨、三列标题层、选中轨、行动背板与独立证据阅读区；普通正文/数字不增加 text-shadow |
| 监控 | HUD 单层 blur、玻璃工具栏、健康弹层、详情壳、终端标题层；终端与表格正文保留稳定数据底 |
| Canvas 节点 | 半透明壳与轻反光标题、98%不透明数据背板，选中节点青蓝轨与局部柔光；没有对 Canvas 文字做像素模糊 |
| 外观设置 | 完整 / 节能 / 减少动态选择，自动持久化；系统减少动态覆盖运动，提示实际生效方式 |
| 图表与多窗口 | ECharts 动画受统一质量/可见性控制，切模式只合并动画标志保留 dataZoom 与数据；受管只读 popout 同步主题/密度/质量，各窗口独立可见性，关闭与主工作台卸载释放监听 |
| chrome 状态读法 | 账户失败不展示旧权益/盈亏，陈旧读取标明非实时；未完成同步信号数量显示未知；状态栏明示同步中/待恢复与失败原因、账户/风控待核对，不把默认 Kill Switch false 写成“未触发” |

没有增加随机波动或伪造脉冲。流量仍来自既有真实观测路径；未知、零流量与熔断不生成流向运动。高分脉冲、急停和异常仍受原业务状态驱动。修改不改变数据订阅、交易授权、风控、账户或下单行为。

## 2. 模式与调度行为

持久化沿用 `nt.settings.v1`，追加 `visualQuality`，兼容旧设置。启动时恢复到 `<html data-visual-quality="full|eco|reduced">`；`data-motion` 表示叠加系统偏好后的实际运动方式；`data-page-visibility` 区分前后台。

| 模式 | 材质 | 运动与更新 |
|---|---|---|
| 完整 | 分层玻璃、局部光轨与柔光 | 只有真实流量/脉冲/状态反馈需要时才续 Canvas RAF；无动态内容不空转 |
| 节能 | 实体壳，关闭 blur 与 glow；焦点描边保留 | 装饰运动停止，数据/选中/拖拽/缩放变化按需重绘 |
| 减少动态 | 保留静态玻璃与光轨 | 装饰运动停止，真实状态仍重绘；急停保留静态风险环 |
| 系统减少动态 | 用户选择保留 | 自动覆盖为无装饰运动，不改写用户保存的模式 |
| 后台 | 保留最近内容 | Canvas 取消待绘帧，不续 RAF；恢复前台绘制最新状态 |

Canvas 帧调度器保证同时最多一个排队帧；销毁时取消并释放监听。既有“页面暂停”同样停止帧调度。CSS 装饰动画及过渡在减少动态/后台停止；节能同时覆盖存量组件的独立 blur/filter。数据处理与关键状态不通过装饰动画驱动。

ECharts 额外关闭系列动画并结束已有图元动画，仍处理并显示最新数据。质量变更只合并动画标志，不覆盖数据或用户缩放；恢复完整模式沿用调用方原有动画开关。图表DOM迁入popout后观察所属文档；外观同步仅复制显示属性，不传递账户/执行授权、不扩大弹出白名单。

## 3. 合成背景可读性

颜色仍以 CSS 为准，新增直接读取 `tokens.css` 的回归测试。计算使用 sRGB 合成与 WCAG 相对亮度比 `(L亮+0.05)/(L暗+0.05)`，覆盖普通 text1–3 在空间底、玻璃/反光、抬升壳、数据背板、选中票行、各域 Canvas 标题及 bg0–bg3；空间场按两个径向场同时达到最大 alpha 保守叠加。

反光与边缘高光分开：暗色正文区域反光 alpha 为 0.065，边缘高光 alpha 为 0.23，只出现在细边；Canvas 域色标题底 alpha 为 0.035。避免把高光的 0.23 直接涂在正文背景后使辅助字低于阈值。

| 验证范围 | 计算最小对比 |
|---|---:|
| 暗色普通文字，含上述合成层 | 约4.61:1 |
| 亮色普通文字，含上述合成层 | 约4.67:1 |
| 亮色强调/风险/涨跌小字，bg0–bg3 | 约4.56:1 |

为保证亮色活动标签等小字的可读性，本批校准以下亮色值；暗色基础配色保留：

| Token | 更新值 | bg3对比 |
|---|---|---:|
| accent | #00677F | 4.917:1 |
| accent-2 | #2C58C3 | 4.850:1 |
| warn | #875000 | 5.023:1 |
| up | #B52548 | 4.804:1 |
| down / success | #066C4C | 4.901:1 |
| danger（保持） | #B92249 | 4.712:1 |
| info（保持） | #1964B1 | 4.562:1 |

暗色语义小字的回归测试覆盖实际稳定数据底 bg0–bg2；不把该结论扩展为所有任意叠色。计算是颜色合同检查，不替代真实屏幕、字体抗锯齿与窗口尺寸走查。
