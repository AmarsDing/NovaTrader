# UI 走查 · B5 AH 溢价读出口（2026-10-20）

> 每轮交付带一次 UI 走查（对照 `doc/开发文档/design/01-视觉风格.md`）。**本刀 `web/src` 零改动**（并行会话在场，只核自己文件面）。本片为纯后端读出口（`GET /v1/market/ah-premium`，admin in-gate `/api/market/` 纯前缀反代自动可达），无面板消费方——走查对象是**合同给未来面板的消费规范**，同型先例 B3 `ui-走查-B3-chipdistribution` / B4 `ui-走查-B4-reportestimates`。

## 1. 消费规范（未来 detail/个股面板接入时按此渲染）

- **五态文案**（不落 0、不画假溢价，`0.数据纪律.md`）：`ok`=正常出数；`no_pair`=「该 A 股无 H 配对」显式文案（**不是错误、不告警**）；`missing`=「缺 N 腿：…」按 `missing[].why` 分流——`no_data`/`na_value`（源无报价哨兵）显「暂无报价」不告警，`parse` 显「源数据异常」可警示；`pair_error`/`source_error`=显「配对未知/报价源故障」，属告警通道（数据健康治理先例，同 datasource-health 缺失不满分多留痕口径）。
- **衍生列** `ah_ratio/premium_pct` 为 `number|null`：null 显「—」；
  涨跌色相（视觉规范红涨绿跌）：`premium_pct>0`=A 贵显红、`>0` 为零轴不比价不配色、负值显绿——**折价是合法业务态不得钳 0 截断**（T2 钉）。
- **三腿价格** `a_price/h_price/hkdcny` 为 `number|null`：各腿独立显「—」；
  `"pair_source":"eastmoney_f10"`/`"quote_source":"tencent"` 恒标签可直渲溯源角标。
- **逐腿时刻** `a_time/h_time/fx_time` 是**源内 tick 时刻**（停牌腿=最后成交时刻，不是取数时刻）——新鲜度角标必须按腿内时刻算，不得当「实时新取」——proto 注释已钉（对面条件④）；`as_of` 才是服务侧合成时刻。
- **停牌腿**：`a_traded=false` 时价格照常回波（源最后成交价），面板建议显「停牌（最后成交 HH:mm）」样式——照算透出而非剔除（T7 钉）。
- **配对事实列**（a_code/a_market/a_name/h_code/h_name）status≠ok 也照常回波——面板骨架可先渲名称与代码再等价格，不白屏。

## 3. 发现项

无代码面改动 → 无 UI 发现项。登记待消费时复核两条：①面板按 `missing[].why` 小枚举分流文案（不要一律「数据异常」）；②停牌腿时刻文案（不要当实时新取谎标新鲜度）。

## 4. 复核后增量（2026-10-20 对抗复核闭环后补）

web/src 仍零改动。后端修复改变三条消费面事实，消费规范已覆盖、此处钉实现层面的兑现度：

- **`why=parse` 现在真正可达**（复核前行级畸形被错桶 no_data、parse 只有数值子项可达）：截断行/非有限值（NaN/Inf）/负价/数值垃圾 → `why:"parse"`。§1 分流文案（parse=「源数据异常」可警示）按原样执行即可，无需改。
- **截断行在场价会被捞救回波**：面板可能见到「a_price 有值而 a_time 缺省」的组合（时刻下标被截断）——时刻列本就 `string|null` 口径，显「—」即可，**不得因时刻缺而把价也隐去**（取到的不丢，后端纪律正面例）。
- **`source_error` 现覆盖「2xx 但源整体坏」**（三符号全缺/不可切分），不再只有传输层失败——告警文案勿写成「网络故障」，写「报价源故障」。
- **NaN/Inf/负价已被源头拦截**：服务端绝不向面板下发非有限或负的腿价/衍生值（proto3 JSON 对 NaN 会序列化为字符串 `"NaN"`，该形态被拦在 why=parse 不会到达面板）；面板 JSON 解析层无需为非有限字符串做兜底，但若见到 `"NaN"` 字符串值应视为接口异常告警而非数据。
