# N5-03 预测归档与离线评价 · 2026-10-16

独立 research-worker 新增 `prediction_archive` 与 `prediction_evaluate`，沿用 N4 manifest/file/hash 合同。当前为文件协议与 CLI，未给生产价格、订单或 M12 开放预测概率/区间。

预测目标固定 `fee_net_next_open_to_close_return_v1`：明确证券、模型/特征版本、预测起点、交易日历版本、下一期开盘入场与至少下一交易日收盘退出（T+1）、双边费用/滑点 bps。归档保留 raw score 的 `uncalibrated_rank/unvalidated_return_estimate` 含义，拒绝把分数命名为已校准概率。真实 prospective 必须在创建后五分钟内且入场前归档，拒绝模型/数据未来信息和后补历史预测。真实/合成 origin 分开。

归档保存于输出根目录 `prediction-archive/<prediction_id>/forecast.json`，跨 run_id 使用独占目录认领；同内容重试幂等、同 ID 改内容拒绝，调用方得到文件 SHA 和内容 hash。各条记录独立原子落文件，批次不是数据库事务；进程崩溃留下的 incomplete 条目拒绝覆盖。此为应用层不可变合同，文件系统管理员仍可改文件，不宣称公证时间戳或 WORM 存储。

评价只读取指定 archive SHA 的既有预测。标签必须显式确认入/出场、费用与可用/观察时间；缺成交、停牌、封板、缺价、未结清退市、晚到标签显示 unknown，不能补零收益。明确退市清算为零时允许 -100% 标签。目标为单位名义金额的费用后收益，不替代账户 NAV，不覆盖最低佣金、股数取整或组合资金约束。

按标签已知时间净化 calibration/gap/test 边界，禁止混用 horizon/model/cost/origin，也禁止以重复 symbol/entry/exit/model 改 ID 扩大样本。至少 200 条校准样本且有两类标签、100 条样本外标签才运行真实 scikit-learn isotonic；规则 score 用相同校准，另比较训练先验 Brier 与现金 0 收益。报告 Brier、10-bin ECE、coverage、未知原因、市场状态/流动性样本数与观测范围，以及训练分箱的 PSI 分布漂移。校准产物只包含训练标签 hash；测试标签变化不能改变拟合产物。PSI 是描述指标，不宣称统计显著性。

即使 synthetic 完整通过，仍 `production_approved=false/display_probability=null`。真实证据不足时 `calibration_state=unknown`，Brier/ECE 为 null；offline fit 也只允许研究用途，未通过独立生产准入。当前没有真实前瞻样本、模型优势结论、条件区间置信覆盖率或生产展示。

实际执行：独立 .venv 的 `python -m unittest discover -s tests -v` 共 20 项 PASS（N5-03 新增 6 项），无跳过。包括归档不可改写/幂等、前瞻时限/未来模型/T+1、费用与无法成交/退市标签、真实 isotonic 对 200/100 个明确合成观测拟合评价、变更测试标签不影响校准工件、缺样本 unknown、档案篡改、完整 CLI 文件协议回路。所有观测均明确 synthetic，不计入实证或交易准入。
