# N5-02 / N6 研究适配实施记录 · 2026-10-16

## 已落地

Jev 采用官方 `POST https://api.typesafe.ai/v1/systemone` 的 state/model/questions 与 noul/choice/score 合同，固定 `jev-1.13.0`，拒绝浮动别名和模型不一致。10 月 16 日复核官方 [API](https://docs.typesafe.ai/api)、[models](https://docs.typesafe.ai/models)：1.14 为预览，本轮没有自动升级。`backend/pkg/fastjudge` 提供真实 HTTP 适配、结构/概率/usage 校验、有效期与公开数据政策、4 秒截止、429/529 有界重试。超时、缺字段、未知类型/证据或预算耗尽均弃权。

`intel SaveScored` 成功提交后提交影子观察，最多 2 并发，无等待队列；旁路结果只进 `llm_call_log`，不覆盖规则/LLM 原评分，不参与风控、价格或订单。`NT_JEV_ENABLED=true` 才初始化，`NT_JEV_PUBLIC_SOURCES` 默认空，仅允许 cninfo/eastmoney 且核对 URL 域名；研报、社交、推测发布时间排除。密钥仅 `NT_JEV_API_KEY` 服务端环境；`NT_JEV_MODEL` 必须版本固定；`NT_JEV_MAX_REQUESTS` 是每进程请求尝试上限，默认 100、最多 10000，**不是跨实例每日费用预算**。异步退出可能丢失尚未完成的影子观察；没有持久重试队列或缓存。监控计数含提交、容量丢弃、弃权、审计失败和最后时延。

审计含请求/输入快照/hash、问题版本/hash/ID、请求/实际模型、usage、耗时/次数/HTTP 状态、截止和弃权原因。原正文、URL 凭据和 provider 错误原文不写日志；`input_excerpt` 留空。审计写失败只记计数，不影响情报主链。尚未使用托管 API key 发起真实 Jev 请求，也没有 500 条真实人工中文标注或有效性结论。

独立 `research-worker` 已提供冻结文件作业协议、不可覆盖运行目录、环境/输入/产物指纹、失败状态与 CLI。接入 N4 的精确 manifest_json 导出，Python 使用 Decimal 对齐 Go 数字、转义与 record/revision 哈希；禁止未来或未知 available_at 记录。实际安装在本目录 .venv 的 QuantStats 0.0.86 和 PyPortfolioOpt 1.6.0，完整安装锁在 requirements.lock.txt，生产 pyworker 未增加重依赖。

QuantStats 输入同一费用后日 NAV/初始点、显式基准与现金流政策；总收益、252 年化、回撤与样本 Sharpe 和 Go 口径参考逐项对照。PyPortfolioOpt 实际执行收缩协方差和最小方差求解，检查现金、单股/行业、锁仓、换手与残差；仅输出影子权重。vectorbt 许可/版本闸口和 RD-Agent 隔离命令已实现，但未安装/执行 vectorbt、未执行 RD-Agent 容器。RD-Agent 只挂载哈希白名单文件及隔离输出，固定离线镜像、不传账户或模型凭据；输出轮询上限不是硬磁盘配额。研究工具尚未接入 Go 持久任务队列、权威 NAV 自动导出或 M12 实时进度，LEAN 可选未实施。

## 官方依据

- [QuantStats](https://github.com/ranaroussi/quantstats)：传入 Series 的指标/报告，避免以 ticker 自动下载另一套基准。
- [PyPortfolioOpt](https://pyportfolioopt.readthedocs.io/en/latest/MeanVariance.html)：明确求解器与权重约束；不把最小方差称为风险平价。
- [vectorbt LICENSE](https://github.com/polakowo/vectorbt/blob/master/LICENSE.md)：Commons Clause 需结合实际用途核验；worker 默认禁用。
- [Microsoft RD-Agent](https://github.com/microsoft/RD-Agent)：Linux 研究作业，仅隔离执行，不持有交易能力。
