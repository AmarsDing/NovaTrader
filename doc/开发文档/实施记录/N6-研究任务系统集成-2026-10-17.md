本记录接续 [N5-02/N6 独立 worker](N5-02-N6-研究适配-2026-10-16.md) 和 [N5-03 预测归档](N5-03-预测归档与离线评价-2026-10-16.md)。16 日“尚未接入 Go 调度”边界已由本批补齐；正式账户 NAV 自动导出、模型有效性、生产候选晋级和实盘交易不在此闭环内。

## 数据流与真实行为

`Research protobuf HTTP/gRPC → ResearchService → ResearchUsecase → N4 Source.GetDataset/Verify → ent ResearchJob + 同事务 outbox → ResearchRunner → revision CAS 认领 → 冻结文件导出 → 独立 Python -I worker → 产物字节/hash复核 → ResearchJob终态 + outbox → sys.research`。

新增共享 `research_job` schema，由主任务集中生成 ent。输入 kind、run_id、manifest_id/hash、原文 JSON、input_hash、as_of、seed、timeout 与创建身份在 ent 合同中不可变。每次研究创建新 UUID；没有改写输入或直接激活策略/订单接口。输入是精确 JSON 字符串，Go decoder 使用 Number，manifest 仍由 N4 从数据库加载并复核，未借 protobuf.Struct 让大整数失真。输入/选项最大各 4MiB，拒绝账户 ID/credential/API key 等字段。

任务状态为 queued/running/succeeded/failed/cancelled/timed_out/rejected/unavailable，revision 单调递增。状态与 `sys.research` outbox 同事务提交；事件只含身份、状态、原因和哈希，不带输入。EntityID/CorrelationID 都是 run_id，EntityVersion 是 revision。即使 NATS 不可用，PostgreSQL 状态仍是真值，outbox 后续投递。

每个服务进程 1 个研究执行者；revision CAS 保证多实例只认领一次。认领记录 owner 与 `timeout+30s` 的租约。取消待执行任务立即终止，取消执行中任务置持久标志，250ms 轮询取消进程；完成写回会再次检查取消，因此取消不会被成功覆盖。过期租约只变为明确失败/取消，不自动重放有外部工件副作用的任务。迟到的旧 owner 完成结果不能覆盖终态。可通过新 run_id 创建相同输入重做。

实际执行器使用服务端固定绝对 Python/script/root 路径，不接受 API 提供程序、命令或路径。只通过允许的系统环境项启动，API/模型/账户密钥不传递。BLAS/Numba 固定 1 线程，单任务壁钟 1–300 秒；Windows 隐藏进程并按已启动 PID 取消进程树，Unix 独立进程组取消。输入目录独占创建，失败也不可复用。结果 JSON ≤4MiB，工件 ≤1000 个、总计 ≤64MiB，逐个校验路径、常规文件/链接、长度和 SHA，核对 worker 产物清单 hash；下载只允许已登记且再次通过校验的工件，单次下载 ≤8MiB。

`ResearchJob.artifact_hash` 是 Go 复核后完整 result.json 的 SHA256；result_json 内 `artifact_hash` 是 Python 的工件列表 canonical SHA。两者定义不同，均保留，不能混用。result.json 另存数据库供 API 读取，其他工件保存在配置的运行根目录。

## 开关与接口

默认 `NT_RESEARCH_ENABLED` 不为 `true`，创建请求返回 disabled，后台不执行研究。启用时配置以下服务端环境，修改后重启 backtest：

```text
NT_RESEARCH_ENABLED=true
NT_RESEARCH_PYTHON=<research-worker 独立 .venv Python 绝对路径>
NT_RESEARCH_SCRIPT=<research-worker/worker.py 绝对路径>
NT_RESEARCH_ROOT=<专用可写运行数据目录绝对路径>
```

固定 HTTP 路由由新 `api/backtest/v1/research.proto` 生成并在 backtest 2071 注册，gRPC 2072 同时注册；服务 main/Wire 已加入 ResearchRunner。admin 的 `/api/backtest` 转发/权限与审计由主任务接入。

| 路由（前缀 `/v1/backtest`） | 行为 |
|---|---|
| POST `/research/jobs` | kind、manifest_id、as_of、input_json、options_json、seed、timeout_seconds 创建不可变任务 |
| GET `/research/jobs?status=&limit=&offset=` | 分页状态，最多100条 |
| GET `/research/jobs/{run_id}` | 状态/revision/时刻/result_json/产物身份 |
| POST `/research/jobs/{run_id}/cancel` | 持久取消，重复请求幂等 |
| GET `/research/jobs/{run_id}/artifact?name=` | 返回登记工件 name/sha256/content(bytes)，不会执行 HTML |

服务支持 performance/portfolio/vectorbt/jev_evaluate/prediction_archive/prediction_evaluate。vectorbt 仍受 worker 显式许可与固定版本闸口约束。RD-Agent 需要本地 Qlib 特征文件和审核镜像，当前只保留离线 CLI 沙箱入口，API 明确拒绝该 kind，不允许绕过路径策略上传任意文件或命令。

## 仍需独立验收的边界

宿主 Python 只执行仓库中受控适配器；它不是 OS 安全沙箱，没有宿主网络禁用或硬 CPU/内存配额。当前线程、壁钟、输入/产物预算不能称为硬资源容器。RD-Agent 的容器隔离仍是独立路径。多个服务实例各1并发，不是集群总并发上限；暂无研究队列全局容量/磁盘保留策略。服务停止/进程崩溃不会自动重跑；运行目录仍需备份与保留策略，多实例部署需共享工件存储或按节点路由。

输入 NAV/收益矩阵仍由调用方提供明确口径，系统尚未自动从正式账户账本导出完整净值。哈希不证明会计真实性或历史授权。真实市场样本、500条中文人工标签、托管 Jev、vectorbt许可准入、RD-Agent真实镜像、LEAN对照、实证预测校准、UI长时间压力与生产交易均未以这些合成测试替代。
