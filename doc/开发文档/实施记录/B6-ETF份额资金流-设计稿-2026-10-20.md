## 2. 数据流（B6a）

```

SZSE fund.szse.cn/api/report/ShowReport/data ─┤
 (CATALOGID=1000_lf&selectJjlb=ETF, 当日快照: T 晚预估 / T+1 早确认, 历史不可查)
        ↓ datahub 两个新 Go 直连源 sse / szse（eastmoney.go 模板，§4.5 通道①）
   CollectEtfShare（biz）→ UpsertEtfShare（data，OnConflict 幂等 + captureDataset
   同事务落 dataset_record + withReady 发 md.etf_share.ready）
        ↓
   ent 表 etf_share（唯一键 symbol+trade_date+as_of，多 vintage）
        ↓ M02 market 读侧（B1–B5 先例）
   biz 读最新 vintage（max(as_of)≤查询日）+ 份额变动推导（delta=t−前一有行日）
        ↓
   market.proto GetEtfShares（proto-first）→ service 指针直传

```

源 → 市场位映射在源内静态完成（SSE 行 → `{SEC_CODE}.SH`，SZSE 行 → `{code}.SZ`），**不经过** `symbol.FromAShareCode`/secu()（其注释明写基金段不可用，`pkg/symbol/symbol.go:45-46`）。

单位：源原单位**万份**落库（equity_unlock 单位随源先例，其注释为「万股，与源 ABLE_FREE_SHARES 口径一致」，`ent/schema/equity_unlock.go:28`），列注释钉单位；A-Stock 调研「禁统一盲乘」纪律遵守。

## 3. 表口径（ent schema `backend/ent/schema/etf_share.go`，追加式）

| 列 | 型 | 口径 |
|---|---|---|
| symbol | string MaxLen16 | 内部形 `510050.SH` / `159915.SZ` |
| trade_date | pgDate | 份额所属交易日：SSE=STAT_DATE；**SZSE=cols.dqgm 列头内嵌日**（P3 实证：metadata.subname=页面日（2026-10-20）≠数据日，dqgm 列头形如「当前规模（万份）…（2026-10-19）」正则抽 `（(YYYY-MM-DD)）`——vibe 读 subname 的口径被活源证伪，以列头日为准） |
| as_of | pgDate | 观测 vintage 日（采集日）。SZSE 预估（T 晚）与确认（T+1 早）同 trade_date 双 vintage 并存；消费侧取 max(as_of)≤查询日（stock_factor 先例）。上游发布时刻无证据 → dataset_record.available_at 保 unknown，**严禁采集时钟冒充**（dataset.go:19-25 N4-01） |
| shares | numeric(24,4) | 万份，与源头一致；ETF 份额恒正，源未给=列不出该券行（无行≠0） |
| etf_type | string Nillable | SSE 口径（单市/跨市/跨境等）；两市**分列不混**（vibe 实证 astock_ported.py:997-999） |
| fund_category | string Nillable | SZSE 口径（tzlb 投资类别） |
| name | string | 快照冗余（SEC_NAME/jjmc） |
| manager | string Nillable | SZSE glrmc 管理人；SSE 源无 → NULL |
| listing_date | pgDate Nillable | SZSE ssrq 上市日期；SSE 源无 → NULL |
| source | string MaxLen16 | `sse` / `szse` |
| updated_at | timestamptz | 写入时刻 |

唯一键 `(symbol, trade_date, as_of)`，index(trade_date)、index(symbol,trade_date)。

「0 vs 未披露」哨兵分家（钉③）：shares 只收正值，**解析不到/非有限/非正** → 整行显式跳过（单位无行级运行时信号——由活源探针源级钉：P1 TOT_VOL 万份值域、P3 dqgm 列头明印「（万份）」，列头单位变更即探针红），**行级跳过聚合成一条 Issue（severity=warn，check=etf_share_row）落 `data_quality_issue` 留痕**（0.数据纪律.md §5b「跳过该行+留痕」分工，不照抄东财 f2≤0 静默 skip 先例）；份额变动 delta：**前一个有行日无行 → delta=NULL**（未披露基期），有前行且真变动为 0 → 落 0（真 0 合法）。SZSE 漏采的交易日**永久无行**（源只给最新快照）——缺口诚实呈现，不补假不插值。

## 4. 纪律五态 + 完整性契约

- SSE（照抄 vibe 契约）：`result` 必须 list、`pageHelp.total` 与 len(result) 恰等（不等抛「结果不完整」）、逐行 `STAT_DATE==请求日`（跨日混入抛错）、空 result=「非交易日或尚未发布」显式语义（**不是错误不告警**）。服务端压 pageSize=2000 先例在册，翻页循环到 total。
- SZSE（P3/P3b 实证修订）：**trade_date=cols.dqgm 列头内嵌日**（metadata.subname 系页面日不作数据日，P3 双日错位实证）；dqgm 列头 tooltip 源级明证双 vintage 语义——「该字段T日晚间更新的T日规模仅供参考，以T+1日早间更新的T日规模为准」（逐字引录 cols.dqgm 原始 HTML，vibe docstring 获源端本体证实）；翻页途中 **subname/pagecount/recordcount/dqgm 列头日四元组**任一变即抛（P3b 三页对照稳定实证）；字段 HTML 嵌入正则抽取（sys_key `<u>(\d{6})</u>` / jjjcurl 名称 `<u>` / dqgm `>([\d,\.]+)</a>` / tzlb / glrmc / ssrq），格式变更**显式报错**（代码内建），不按空静默；页大小服务端固定 20、PAGENO 循环到 pagecount（P3 实证 39 页 762 行，末页 2 行）；顶层 payload 是 3 个 tab 数组、只读 payload[0]（CATALOGID=1000_lf&TABKEY=tab1&selectJjlb=ETF 对应 tab）。
- 两源非 2xx/403/429 行首【疑似限流/封禁】标签入 last_error，断路 3 失开/60s 半开（流水线既有）。
- 读出口五态式：`found=false`=窗口内无行（不告警）；披露列 NULL↔proto optional 一一对应；delta 基期缺=NULL；**申赎金额 B6a 不下发**——缺 NAV 源，proto 注释写明「金额推导待 B6b 净值/行情源」，不无源编数。
- source_health 自动入册（persist 每分钟，验收目视 §8.1①）；§3 速查表补行：**SSE=按日归档可回补 / SZSE=当日快照不可回补**，新鲜度口径不对称属 §8.1② 明写要补的新语义。
