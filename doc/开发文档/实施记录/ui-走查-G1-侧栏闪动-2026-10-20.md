## 1. 视觉需求逐条对照

- **数字更新动效**（1.视觉需求.md:73「顺滑滚动+脉冲光效，而非生硬数字跳变」）：现价单行报价头不做跑马滚字，变更反馈走背景光效 300ms 内淡出（`qs-flash-up/down`，quote-sidebar.panel.vue:445-453），属「脉冲光效」档的克制落地，与 MarketView 行情卡同节律。
- **动效表达真实状态**（:175-179 §7.2）：只在前/后两帧快照皆真值且现价**变化**才打标（load() 差分，:78）——切代码 prev=null 不闪、无变化不闪，零假脉冲；单脉冲即息 + 300ms 冷静，同向不重闪、反转立即重闪，不持续闪烁，符合「一次优先突出一条聚焦路径」。
- **红涨绿跌**（:104）与 **token 纪律**（:123, :147）：上/下闪只用 `--nt-up` / `--nt-down`，经 `color-mix(in srgb, var(--nt-*) 32%, transparent)` 合成半透明背景；本批零散写 hex、无色值副本，语义随主题切换不漂移，色觉安全主题同源自动成立。
- **减少动态/节能**（:185）：无组件级动效豁免——三模式经 `data-motion` 与 `prefers-reduced-motion` 的全局 `animation: none !important`（style/global.css:66-79）天然覆盖本 keyframes；节能档零新增闪烁负担。
- **布局稳定与密度**（:113, :121）：`padding: 0 4px; margin: 0 -4px; border-radius: var(--nt-radius-s)`（:431-433）在行盒内补偿光效面积，闪动只换背景不换框盒，行高/密度档无抖动、无重排；发光预算符合「发光是稀缺资源」（单票脉冲 ≤600ms 周期）。
- **文字色阶/对比度**（:148, :193）：`.last` 数字本体色未动；闪动为 32% alpha 语义色背景叠加，不改变文字对比度账——G4 建档（contrast-baseline belowAA 亮色/安全 up|danger@bg-1=4.17）判定不受影响。hero 档 `text-0`（:429）属 M12 显示合同线平行在飞件，与闪动背景的组合复走查见 §4 登记②。

## 2. 帧纪律与性能兑现

- 手写 800ms trailing 防抖 → `dataFrame.scheduleThrottled('quote-sidebar', 800, …)`（:100-104）：固定 key 单节流器不随面板实例增生，合帧/隐藏页降频/负载自适应全权转交帧钟；`offFlash()` 与 disposed 短路卸载干净，无僵尸任务。
- 闪动钟消费侧精确定时不轮询：`quoteFlash.onChange` 回调按 symbol 取样（:56-60），快照引用稳定支持 memo，无自启 rAF 循环。
- 「没取到≠0」边缘：打标仅依快照差分，`q.last` 缺失不参与比较、缺 prev 帧不编假基线；面板对缺失的显式表达（prevClose 守卫行）由 P3-10c 簇持有，本批不重叠。
