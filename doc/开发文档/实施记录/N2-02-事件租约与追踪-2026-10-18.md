# N2-02 事件投递租约与持久追踪

日期：2026-10-18。已实现投递可靠性与持久事件查询，跨全部业务消费者的直接因果和处理ACK尚未完成。

## 投递

共享 outbox schema 追加 `lease_owner`、`lease_until`、`next_attempt_at`、死信时间及错误分类，已用 ent 工具生成。`pkg/outbox/lease.go` 在短事务内用 `FOR UPDATE SKIP LOCKED` 领取一条记录；30秒租约，网络发布在事务外、每次超时10秒。提交发布结果须匹配owner且租约未过期。发布后标记失败仍可能重投，稳定event_id与消费者幂等仍必需。

失败按指数退避，最多12次后进入死信；非法元数据直接隔离，不再阻塞健康记录。存储固定安全错误分类，不记录上游原文或秘密。当前没有死信重放写接口；只读查看不会重放事件。

## 查询

proto `api/admin/v1/observability.proto` 的 GetTrace，认证 `GET /api/ops/traces?trace_id=&limit=`。Gate→data AuditStore→outbox元数据投影，仅返回事件身份、来源、subject、时间、直接父事件与发布状态；最多200条，缺父事件/截断明确标记。不下发原始payload，不将 outbox published 解释成下游业务完成。

`TraceExplorer.vue` 接到原监控工具栏。精确trace查询、有界投递概况、pending/leased/retry/dead等实际状态；关闭和新查询取消旧请求，避免迟到结果覆盖。

## 实际验证

隔离PostgreSQL测试已覆盖多dispatcher只能一方领取、未过期租约不可抢、崩溃租约过期恢复、毒记录不挡健康记录、稳定身份失败重投。网关测试覆盖鉴权、过滤、错误脱敏与只读出口。2026-10-18合并复验由集成记录汇总。

## 仍保留的限制

持久查询覆盖outbox生产记录，既有未使用outbox的普通行情事件不因此持久化；直接父事件只有真实传播过才存在。不提供全消费者业务ACK、完整数据血缘、未接入时钟偏差或全链路P95。历史保留/归档和有审批的死信处置需另实现。

## 同日增补（2026-10-18 晚）：处置回执

本批把「处置回执」落成可审计留痕，但**只标注、不回放**：留痕不触碰 outbox 投递状态，死信仍是死信，重放与处置审批仍需单独实现。

- **表**：共享 ent 新增 `event_dispositions`（schema/event_disposition.go → `go generate ./ent`）：event_id/trace_id/action/note(≤280)/actor/created_at，(event_id)、(trace_id)、(created_at) 索引。追加式新增表，无改列；留痕不可回改/删除（无对应接口）。
- **网关**：`GET /api/ops/dispositions?event_id|trace_id=&limit≤100`（登录可读，viewer 可）；`POST /api/ops/dispositions`（仅 Owner）。event_id/trace_id 走 observationID 有限标识正则；action 五值封闭集 acknowledged/investigating/resolved/ignored/escalated——不含 replay/restart/delete 等后果性动词；note 超 280 字节拒绝。动作加入 sensitive 名单：审计关/写失败一律 503 不放行，与配置保存同口径。
- **读侧**：TraceExplorer（监控工具栏事件追踪浮层）在有精确 trace 且有事件时列出本链路留痕与「只标注」边界注记；Owner 显示目标事件+动作+备注的留痕表单，写后重新拉取列表；非 Owner 明示需要 Owner。契约更新写进监控驾驶舱业务监控方案 §10 只读边界（写操作由一项扩为两项）。
- **实测**：`go test ./app/admin/internal/gateway ./app/admin/internal/data` 通过（新增 TestDispositionReadBoundedAndAnnotatedOnly / TestDispositionWriteOwnerOnlyClosedActionAndAudited：401/400/403、不安全标识与后果动词拒绝、超长备注拒绝、落库写入字段与审计留痕）；前端 vitest `dispositions.test.ts` 3/3（驼峰/蛇形别名、请求形状、非封闭动作本地拒绝）；`go build ./... && go vet ./app/admin/...` 通过。
- **隔离PG验收（2026-10-18 晚补）**：`NT_TEST_PG_PORT=55432 go test -count=1 -run "DispositionRoundTrip" ./app/admin/internal/data` 通过（1.4s）：专用库 `novatrader_admin_contract_test` 上写入两条留痕→按 event/trace 各读回 2 条→(created_at, id) 逆序后写者恒前→limit=1 生效；并断言 WriteDisposition 之后 outbox 行数仍为 0，证明留痕不改投递状态。隔离纪律与 trade/data 合同测试同口径：设了端口连不上直接 FAIL，不容 SKIP 充数。
- **仍未覆盖**：收件人维度（按 actor 汇总）与滞留死信 N 条以上升级；回放/审批工作流仍缺；留痕不进入 WS 推送，靠查询成功后本地刷新。
