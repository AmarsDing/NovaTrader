# 量化交易终端前端界面科技感描述

> 2026-10-14全局配色改版已落地：以第六节“深海控制台”为当前配色基线，保留第五节红涨绿跌、主题/密度及发光预算。前四节的材质、布局与动效描述为早期概念，不能替代当前实现合同。
本界面以**「赛博金融·量化智脑」**为核心设计内核，深度适配DGX Spark私有化AI量化交易场景，摒弃冗余装饰，以「专业金融属性为骨、未来科技质感为皮、高效交易决策为核」，打造兼具沉浸式科技体验与超短线交易实用性的个人量化驾驶舱界面，整体呈现出「低饱和度未来工业风+AI智脑可视化+实时数据全息感」的专属科技质感。

## 一、核心视觉基调与设计内核
### 1. 设计理念
以**「AI驱动的超短线交易控制中枢」**为核心定位，模拟NVIDIA DGX超算控制台的工业级科技风格，兼顾「数据决策的专业性」与「AI算力的未来感」，所有视觉元素均服务于超短线交易的核心需求——**关键信息毫秒级捕捉、AI决策逻辑可视化、风险信号强提醒、操作路径极简**，拒绝无意义的炫技装饰，让科技感完全服务于交易效率。

### 2. 色彩体系
以**深蓝黑（#050D17）**为基底，用深蓝面板、冰青操作色和银白文字构建清晰的层级：
- **主色**：冰青（#45E0FF）用于当前选择、核心操作、信号与路径强调；它表达界面重点，不代表行情已经新鲜或交易已经获准。
- **辅助色**：电蓝（#769DFF）用于模型与第二条图表序列，信息蓝（#66B5FF）用于数据域；琥珀（#FFBB66）用于预警，警戒红（#FF5C7C）用于风险；涨/买入/盈利为红（#FF6B81），跌/卖出/亏损为绿（#35DFB1）。
- **中性色**：从5%灰度到95%灰度的12阶阶梯色，用于界面分层、文字层级、面板分割，通过灰度差构建空间纵深感，避免纯黑纯白的视觉疲劳。

### 3. 材质与光影质感
整体采用**「磨砂玻璃拟态+金属拉丝质感+全息光效」** 三大核心材质，还原超算控制台的工业级科技感：
- 面板材质：大面积使用**20%透明度的磨砂毛玻璃拟态（Glassmorphism）** 面板，搭配1px的内发光渐变描边，呈现半透明的悬浮感，同时通过多层面板叠加构建界面的空间纵深感；
- 控件质感：按钮、开关、滑块采用**微倒角金属拉丝质感**，表面做细微的磨砂纹理处理，hover时触发梯度霓虹光效描边，点击伴随量子跃迁式缩放动效，操作反馈精准且极具未来感；
- 光影体系：摒弃全局主光，采用**局部点光+边缘光效**的赛博朋克光影逻辑，仅在核心数据面板、AI信号模块、操作按钮处添加内发光/外发光效果，模拟超算控制台的指示灯质感，暗部保留足够的细节层次，避免强光刺眼，适配长时间盯盘场景；
- 数据渲染：核心行情数据、AI评分采用**全息投影式字体渲染**，文字边缘添加微弱的光溢出效果，关键数值搭配动态渐变填充，让数字跳动呈现出「全息数据投屏」的未来感。

### 4. 空间布局逻辑
采用**「驾驶舱式环绕布局」**，以用户的决策视线为核心，构建「中心核心区-两侧监控区-底部状态栏」的黄金视觉动线，完全贴合超短线交易的盯盘习惯：
- 中心核心区：占据屏幕60%的视觉重心，固定展示AI超短线选股信号池、实时行情主图，是用户的核心决策区；
- 两侧监控区：左右分栏的悬浮式面板，左侧展示外围市场联动、消息面舆情监控，右侧展示持仓盈亏、风险指标、实时预警，无需切换页面即可全维度监控；
- 底部状态栏：通栏式超算控制台设计，实时展示DGX Spark的算力占用、模型运行状态、系统健康度、数据同步状态，模拟超算主机的运行面板，强化私有化部署的专属科技感。

## 二、核心功能模块科技感细节描述
### 1. 主驾驶舱·全局概览界面
作为系统首页，呈现**「AI量化交易总控台」**的沉浸式科技感：
- 顶部通栏采用**金属质感的导航栏**，左侧是系统LOGO「NovaTrader 智脑」，搭配动态呼吸灯效，标识系统运行状态；右侧是账户总资产曲线、当日盈亏全息数字，盈利时数字呈现渐变绿光，亏损时呈现渐变红光，数字跳动伴随顺滑的滚动动效，无生硬跳转；
- 中心区域是**可交互的资产沙盘**，展示持仓分布、板块仓位、关联标的联动关系，点击单个标的可直接展开详情面板，沙盘随鼠标移动呈现轻微的视差动效，模拟全息沙盘的空间感；
- 四周环绕6个**磁吸式悬浮数据面板**，分别展示「当日信号胜率、累计策略收益、最大回撤、AI模型置信度、市场情绪指数、外围市场涨跌幅」，每个面板均采用磨砂玻璃质感，底部添加对应主题色的发光底座，数据更新时触发脉冲光效，关键指标异常时自动放大并高亮提醒。

### 2. AI智脑·超短线选股信号中枢
核心交易决策模块，深度还原「大模型选股推理全流程」的科技感，是界面的核心亮点：
- 信号池采用**「能量舱式」卡片布局**，每只推荐标的对应一个独立的磨砂玻璃悬浮卡片，卡片顶部是股票代码+名称，核心位置是AI综合评分（0-100分），评分以环形能量条的形式动态渲染，85分以上的高价值标的触发极光青满溢光效，视觉优先级拉满；
- 卡片内部分层展示「消息面评分、技术面评分、外围联动评分、资金面评分」四维雷达图，雷达图采用渐变霓虹线条渲染，每个维度的数值变化实时更新，同时标注核心驱动逻辑，让AI选股逻辑完全可视化；
- 卡片底部是**标准化交易指令区**，标注入场区间、止损位、止盈位，买入按钮采用渐变绿光金属质感，止损预警采用红光高亮提醒，点击按钮触发确认动效，操作路径极简，避免超短线交易的操作延迟；
- 左侧搭配**AI推理链路可视化动效**，以动态数据流的形式，实时展示「数据采集→RAG检索→大模型分析→因子融合→信号输出」的全流程，数据流的流动速度匹配DGX Spark的算力占用，模拟AI智脑的思考过程，让黑箱模型完全透明化。

### 3. 全息行情·多维度实时监控面板
适配超短线盯盘需求，打造「毫秒级响应的全息行情控制台」：
- 主K线图采用**轻量化三维渲染**，K线主体添加渐变填充与边缘光效，成交量、MACD、RSI等技术指标采用分层叠加的半透明霓虹线条，鼠标悬浮时触发十字光标全息投影，精准展示对应时间点的量价数据、消息事件，无遮挡、无冗余；
- 左侧消息流面板采用**「时间轴式」舆情瀑布流**，实时推送A股公告、外围消息、行业政策，每条消息标注AI情绪评分（1-10分），利好消息标注绿光标签，利空消息标注红光标签，突发重大消息自动触发全屏脉冲预警，确保超短线机会第一时间捕捉；
- 右侧外围市场联动面板，采用**「星球联动式」拓扑图**，以A股为核心，辐射美股、港股、汇率、原油、黄金等外围市场，标的之间的联动关系以动态发光线条连接，上涨/下跌分别用绿/红线条渲染，外围市场异动时自动高亮对应传导路径，直观展示外围消息对A股的影响逻辑。

### 4. 策略实验室·回测与模型自省看板
量化开发核心模块，呈现「工业级策略研发控制台」的科技质感：
- 回测报告页面采用**「数据驾驶舱」** 布局，核心回测指标（年化收益、胜率、盈亏比、最大回撤）以全息数字仪表盘的形式展示，每个仪表盘搭配动态指针与渐变填充，指标优劣通过颜色梯度直观呈现；
- 收益曲线采用**三维立体渲染**，策略收益曲线与沪深300基准曲线分层叠加，盈利区间填充渐变绿光，回撤区间填充渐变红光，鼠标悬浮可查看对应时间点的交易明细、策略调仓逻辑，同时支持缩放、拖拽、时间区间筛选，交互顺滑无卡顿；
- 模型自省模块，以**「AI脑图」** 的形式展示策略优化过程，左侧是历史信号准确率的热力图，右侧是策略参数优化的动态迭代路径，每次参数调整都以发光节点的形式呈现，优化前后的效果对比采用双屏悬浮面板展示，直观呈现AI自主学习的进化过程。

### 5. 算力中枢·DGX Spark系统运维面板
私有化部署专属模块，还原「NVIDIA超算控制台」的硬核科技感：
- 顶部是DGX Spark硬件3D建模渲染图，实时展示GPU/统一内存的占用率，内存占用以动态渐变的液体填充效果呈现，超过80%阈值时触发橙色预警，超过90%时触发红色预警；
- 中间区域是**多模型运行状态监控面板**，每个部署的大模型对应一个独立的运行舱，实时展示模型加载状态、推理延迟、显存占用、调用次数，正常运行时模型名称旁添加绿色呼吸灯，异常时自动触发红色告警，并展示故障排查指引；
- 底部是数据同步、系统日志、服务运行状态的通栏监控条，每个服务对应一个指示灯，正常运行时绿灯常亮，异常时红灯闪烁，同时支持一键重启服务、一键备份数据，操作按钮采用工业级金属质感，贴合超算控制台的操作逻辑。

## 三、交互与动效的科技感体系
所有动效均遵循「**高效优先、反馈精准、不干扰决策**」的原则，拒绝冗余动画，让科技感服务于交易体验：
1.  **无感高效交互逻辑**
    全界面支持快捷键全局操作，超短线交易的买入/卖出、信号刷新、预警屏蔽均可通过一键完成；面板支持磁吸式拖拽、自由缩放、分屏悬浮，用户可自定义专属盯盘布局，操作全程伴随顺滑的阻尼动效，无生硬的界面跳转；核心信号弹窗采用「边缘滑入」的动效，不遮挡主行情界面，确保盯盘不中断。

2.  **数据可视化动效设计**
    所有实时数据更新采用「顺滑滚动+脉冲光效」，而非生硬的数字跳变；K线图随行情实时推进，新生成的K线伴随渐变填充动效，成交量峰值触发柱状发光效果；AI评分、收益曲线的更新采用渐进式动画，完整呈现数据变化的过程，而非瞬间跳转，视觉体验更流畅。

3.  **状态反馈与预警动效**
    常规操作采用「微缩放+轻微光效」的弱反馈，不干扰盯盘；重大信号、风险预警采用「全屏脉冲光效+边缘红光描边+声音提示」的强反馈，确保极端行情、突发机会不被错过；止盈止损触发时，对应标的卡片会持续闪烁提醒，同时推送弹窗确认，避免交易机会流失。

4.  **空间层级动效**
    界面切换采用「Z轴空间缩放」的转场动效，从总控台进入详情面板时，伴随镜头推进的视差效果，模拟进入超算子系统的沉浸感；面板展开/收起采用「渐变透明+缩放」的组合动效，全程无卡顿、无割裂感，构建出清晰的界面空间层级。

## 四、专属科技感亮点
1.  **AI推理全链路可视化**
    区别于传统量化软件的「黑箱信号输出」，本界面实时渲染大模型从数据采集、消息解读、技术分析到信号生成的全链路过程，以动态数据流的形式呈现AI的「思考路径」，让每一笔交易推荐都有迹可循，同时直观展示DGX Spark的算力调度过程，强化私有化AI超算的专属科技感。

2.  **极端行情沉浸式预警体系**
    针对超短线交易的极端行情场景，构建多级预警机制：大盘暴跌、持仓标的触发止损、突发重大利好/利空时，界面自动触发对应颜色的全屏渐变光效，同时锁定核心操作按钮，推送标准化应对方案，既保证预警的强提醒，又避免用户在极端行情下的情绪化操作，科技感与实用性完美结合。

3.  **多屏联动适配**
    界面原生支持多屏扩展，主屏展示核心信号与行情，副屏分别展示外围监控、策略回测、系统运维面板，多屏之间数据实时同步，操作无缝衔接，模拟专业交易员的多屏控制台，进一步强化私有化量化交易系统的专业科技感。

4.  **暗黑/纯白模式一键切换**
    除了核心的深空黑科技模式，同步适配纯白高对比度模式，白天强光环境下一键切换，模式切换伴随全局颜色渐变动效，所有面板、控件、数据可视化效果同步适配，兼顾不同场景的使用需求，同时保持统一的科技质感。

## 五、重构补充约定（2026-10，前端整体重构时确立）

以下三条为本轮重构新增硬约定，与上文冲突处**以本条为准**。

> 2026-10-15 更新：本节第2条的玻璃与发光使用范围被第七节的新用户要求取代；红涨绿跌、主题/密度、统一token与可读性仍有效。第六节为已实现配色，第七节材质与三种显示模式已落地，交互和完整性能验收按任务书继续。

### 1. 涨跌色：红涨绿跌（A 股约定）

- `--nt-up: #FF6B81`（涨/买入/盈利），`--nt-down: #35DFB1`（跌/卖出/亏损）。亮模式使用第六节深色对应值。
- 上文出现的「上涨绿/下跌红」表述（如第三节可视化、联动拓扑线）一律反向执行。
- 语义色：`--nt-danger`用于风险/Kill Switch，与涨跌方向分别判断；`--nt-warn`为琥珀预警，`--nt-accent`为冰青操作/强调色。
- 判定方向只走 `format.ts` 的 `pnlClass()/pnlSign()`，CSS 只认 `.up/.down` 类，禁止散落判断。

### 2. 玻璃拟态与发光预算（专业克制版）

参考 Bloomberg Terminal / Linear 的克制密度：信息密度优先，发光是稀缺资源。
- 玻璃模糊（backdrop-filter）**只允许出现在三处 chrome**：CommandBar、弹层（Modal/Confirm）、极端预警 AlertCenter；数据面板一律纯色 `--nt-bg-1` + 1px `--nt-border-1`，无 glow、无渐变描边。
- 发光效果（box-shadow/text-shadow glow）只保留给：**AI 信号分 ≥ 85 的高价值标记**、**风险预警**、**Kill Switch 激活态**三处；其余（按钮常驻 glow、卡片底座光、全息描边）全部移除。
- 删除常驻扫描光/呼吸灯动画；hover 反馈降为 1px 描边 + 微缩放；保留 `:focus-visible` 青色焦点环与 sticky 表头。
- 数字渲染：所有行情/金额/评分数字走等宽数字 `--nt-font-mono` + `tabular-nums`，不再使用全息渐变字。

### 3. 密度与主题切换

- `<html data-density="normal|compact">`：compact 下行高 22px、单元格 padding 2px/6px、字号 12px（token `--nt-row-h` / `--nt-cell-pad`），设置面板可切换。
- `<html data-theme="dark|light">`：dark 为主；light 用白底阶梯 + 投影替模糊、语义色明度降 10%，P5 交付切换入口（设置面板先行）。
- 所有间距/字号/颜色只能从 `theme/tokens.css` 令牌取，禁止散写硬编码色值。

> 布局形态（dockview 工作台、命令面板、多屏）见 `M12-桌面客户端/设计文档.md`，本文不重复描述。

## 七、视觉深化：深海霓虹玻璃控制台（2026-10-15，材质已实施，完整验收继续）

### 7.2 动效表达真实状态

- 原布局不推翻，默认主链位置与用户偏移保留；根因/聚焦路径突出，其余结构降低亮度。
- 已知真实事件可驱动短脉冲，数值仍带单位、统计窗和采样时刻；未知或零流量静止。不得用随机粒子、GPU负载或轮询成功模拟业务传输。
- 关键状态先更新，动效随后反馈；告警短时强调后保留静态原因，不持续全屏闪烁。一次优先突出一条用户聚焦路径。
- 推理阶段是可审计的任务/调用进度与证据摘要，不能称为模型内部思考链。
- 历史回放显著标记，真实交易入口不可用；恢复实时先同步权威状态。
