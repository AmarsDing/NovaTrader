## 0. 背景与评审结论

2026-10-21 评审结论（代码实证口径）：

- 13 个模块无空壳（5 完成 / 8 部分），**文档声称完成度 ≈85%，端到端实证完成度 ≈60%**。
- 系统当前形态 = **规则驱动的模拟盘半自动系统**：AI 未接（M05/M03 全天候规则降级）、信号恒 ai_degraded（M06 四上游端口未接）、自动买入第一跳靠人工点页面（无信号→计划消费者）、LIVE 实盘被结构性封死（remote.Submit 零调用方、LiveEnabled/BrokerConnected 恒 false 无 setter）、实盘回报入账消费者未建、知识库案例不自动沉淀也不反喂。
- 主路径四处断点：**5→7 信号→计划人工首跳、7→8 LIVE 出口未接线、8→9 回报通道未建、11→12 案例归因回填与反喂断链**；外加贯穿全链的「模型未配」环境断。

## 1. 总目标

**G1（最小闭环，P0）**：在模拟盘上实现「实时行情 + 消息 → 四维分析（LLM）→ 信号 → 风控 → 自动买入/卖出 → 回报 → 复盘 → 归因」的无人值守闭环，并具备放行至半自动实盘的全部代码条件（准入按决策 3：模拟盘连续满 20 交易日 + 审批）。

**G2（设计承诺，P1）**：情报 LLM 评分生产化、知识库 RAG 接入研判与案例学习闭环、信号级预测检验、外围量化因子、通知链路补全、黑名单单轨化、LLM 归因叙述。

**G3（治理红线）**：任何学习产生的权重/参数变更必须留 strategy_version 快照可回滚，人工批准门默认保留；ai_degraded 下自动开仓需显式允许；LLM 出网有白名单与脱敏口径，密钥不落明文。

## 2. 非目标

- 不改写决策 1–4（Tauri 桌面、PG+ent、通达信行情/东财文件单、文档按模块维护）。
- 不做提案自动批准为默认（仅留可选白名单模式，P2）。
- 不逆向交易接口、不点击客户端、不引入 QMT。
- 环境类验收（真实 20 交易日、东财真机、DGX vLLM 部署）只建载体与 SOP，不在本模块代码任务内完成。

## 4. 总验收门

1. **演示日门**：任一交易日从 08:30 晨报到 15:55 复盘全部自动产出，盘中至少一条 LLM 参与的非降级信号经自动消费者完成 SIM 买入闭环（含风控前置与通知推送）。
2. **准入门**：E02 通过后 system 具备申请半自动实盘资格（L2）。
3. **代码门**：backend `go build ./... && go vet ./...` 干净；改动包 `go test` 全绿；web 改动过 `vue-tsc`/`eslint`。
