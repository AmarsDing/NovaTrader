## 首装

```powershell
# 打包（排除 node_modules / .git / dist）
cd E:\project\NovaTrader
tar --exclude=.git --exclude=node_modules --exclude=web/node_modules --exclude=web/dist --exclude=backend/bin_deploy -czf $env:TEMP\nt-src.tgz .
scp -i $env:USERPROFILE\.ssh\hcf44_ed25519 $env:TEMP\nt-src.tgz dingsheng@192.168.4.44:/tmp/
```

44：

```bash
mkdir -p /home/dingsheng/novatrader/src /mnt/exdata/novatrader/data
tar xzf /tmp/nt-src.tgz -C /home/dingsheng/novatrader/src
cd /home/dingsheng/novatrader/src/deploy
cp env/env.example env/.env
PW=$(openssl rand -hex 16)
sed -i "s/^PG_PASSWORD=.*/PG_PASSWORD=$PW/" env/.env
chmod 600 env/.env
# 脚本内已 sudo 包装 docker；长任务勿用管道吞退出码
bash scripts/deploy.sh > /tmp/nt-deploy.log 2>&1
echo EXIT=$?
tail -80 /tmp/nt-deploy.log
```

## 降级与不做

- 无通达信本地行情、无 broker-gw 实盘文件单（仅 Windows）
- LLM `base_url` 空 → 规则分
- pyworker 角色默认 `akshare,baostock`

## 踩坑（继承 HCF/Twin 实录 + 本次）

1. docker permission → 必须 sudo 密码管道  
2. IPv4 pool 耗尽 → 显式 `10.181.0.0/24`，勿手动 `docker network create` 后交给 compose  
3. 改网络属性后容器可能仍挂旧网 → deploy.sh 会核对 `nt-net` 并 force-recreate  
4. Hub 直连不通 → `pull-images.sh` 走 daocloud retag，不动 daemon.json  
5. kratos 不展开 env → 只认 `render_config.sh` 产物卷挂载  
6. `.env` 取值只能 `source`，禁止 `grep|cut`（行尾注释会污染端口号）  
7. **pgvector:pg18** 数据卷必须挂 `/var/lib/postgresql`（不是 `.../data`），与 aranea 一致  
8. 日志/密钥目录属主须为容器用户 `10001`（`chown -R 10001:10001 .../app-logs .../secrets`）  
9. Windows 打包的 `.sh`/`.env` 若含 CRLF，44 上先 `sed -i 's/\r$//'`  
10. 多进程同容器启动时先起 datahub 再起其余，避免 `CREATE EXTENSION vector` 竞态
