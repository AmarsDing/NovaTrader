以下针对性并发检测命令通过（在 `backend/` 下执行）：

```powershell
$env:NT_TEST_PG_PORT = '55432'
$env:NT_TEST_NATS_URL = 'nats://127.0.0.1:14222'
go test -race ./pkg/events ./pkg/outbox ./pkg/accountstate ./app/trade/internal/... ./app/risk/internal/... ./app/admin/internal/gateway ./app/admin/internal/server ./utils/websocket -count=1
```

测试入口仅以显式 `NT_TEST_NATS_URL` 连接隔离 loopback 非默认端口，拒绝 4222；缺少变量时相关 NATS 集成测试会跳过，后续运行须据实际结果区分“通过”与“跳过”。数据库测试支持 `NT_TEST_PG_PORT` 指向隔离实例。
