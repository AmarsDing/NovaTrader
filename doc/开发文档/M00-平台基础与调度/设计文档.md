## 1. 时段状态机

时区固定 `Asia/Shanghai`。非交易日全天 `CLOSED`。

```
CLOSED → 07:30 PRE_OPEN → 09:15 CALL_AUCTION → 09:25 PRE_MATCH
      → 09:30 AM_TRADING → 11:30 NOON_BREAK → 13:00 PM_TRADING
      → 15:00 POST_CLOSE → 15:30 CLOSED
```

14:30 起 `PM_TRADING` 带子状态 `LATE_SESSION`。每次变化发 `sys.session.changed`。

## 2. 自动建库

1. 连接 `postgres` 系统库。
2. 若没有 `novatrader` 则 `CREATE DATABASE`。
3. 连接业务库，拿 PostgreSQL advisory lock。
4. 执行 ent `Schema.Create`。新字段必须有默认值。
5. 需要 pgvector 时，在迁移前执行 `CREATE EXTENSION IF NOT EXISTS vector`。这是基础设施语句，封装在 `pkg/dbinit`，业务代码不写 SQL。

`CREATE DATABASE` 不能放进事务。

## 3. 事件

关键业务（订单、信号、风控、告警）走 NATS JetStream，至少一次，消费端幂等。行情快照走普通 NATS，不落盘。

写库和发事件用 Outbox：同一事务写业务表和 `outbox`，后台再投递。

| `pkg/dbinit` | 建库、迁移锁、pgvector 扩展 |

## 5. 端口

admin HTTP 2001、gRPC 2002、WebSocket 2003。其余服务 http=20x1、grpc=20x2，从 datahub 2011 起。客户端只访问 admin。

已分配：intel（M03、M04）HTTP 2031、gRPC 2032；backtest（M07）HTTP 2071、gRPC 2072，客户端经 admin `/api/backtest/*` 转发；brain（M05）HTTP 2051、gRPC 2052；notify（M10）HTTP 2101、gRPC 2102。
