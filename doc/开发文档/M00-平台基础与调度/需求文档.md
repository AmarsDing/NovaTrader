# M00 平台基础与调度 · 需求文档

| 项 | 内容 |
|----|------|
| 模块 | M00 |
| 服务 | `scheduler`、`pkg/dbinit`、`pkg/events`、`pkg/ashare` |
| 版本 | v0.2 |

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-00-01 | A 股交易日历，含节假日和调休 | P0 |
| FR-00-02 | 交易时段状态机。各服务禁止自己用时钟猜「现在是不是盘中」 | P0 |
| FR-00-03 | 任务：cron、仅交易日、依赖、超时、重试、漏跑补跑、执行记录 | P0 |
| FR-00-04 | 启动时自动建库，再用 ent 建表。多服务同时启动只迁移一次 | P0 |
| FR-00-05 | 服务注册与心跳 | P0 |
| FR-00-06 | Token 与密钥加密存放，日志脱敏 | P0 |
| FR-00-07 | NATS 事件信封：event_id、trace_id、时间、来源。消费端按 event_id 去重 | P0 |
| FR-00-08 | 统一错误码、结构化日志、链路追踪 | P1 |
| FR-00-09 | 策略与风控参数可热更新，变更可回滚 | P1 |
| FR-00-10 | PostgreSQL 与配置每日备份 | P1 |

验收：连续 20 个交易日，任务按时触发率 ≥ 99.9%；节假日不误触发。

数据库只使用 PostgreSQL。向量用 pgvector 扩展。不新增 TDengine、ChromaDB、Neo4j、SQLite 业务库。
