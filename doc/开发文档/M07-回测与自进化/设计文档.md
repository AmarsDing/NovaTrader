## 0. 评审结论（v0.2 → v0.3）

| # | v0.2 的问题 | 处理 |
|---|-------------|------|
| 1 | 未来函数自检写成「打乱未来数据后结果应明显变化」。打乱未来数据后收益一定会变，这条检查永远通过，查不出任何问题 | 改为截断比对：切点日之后的数据打乱重跑，切点日之前的成交和权益必须完全相同。见第 7 节 |
| 2 | 「查询时再算前复权」。前复权用的是最新复权因子，回测里等于提前知道以后的除权 | 按决策日复权；持仓跨除权日按现金等值入账；涨跌停按除权参考价。见第 4 节 |

| 7 | 成交量上限 10% 后「超出部分不成交」，但 `sim.Book` 只能整单成交，也没有资金和费用；撮合规则不在共享包里，模拟盘无法「同一实现」 | `pkg/brokerif/sim` 增加纯函数 `Match`、部分成交 `FillQty`、带资金和费用的 `Account`。模拟盘与回测共用 |

## 2. 用什么数据

| 数据 | 表 | 用法 |
|------|----|------|
| 日线 | `market_data` freq=`1d`，`bar_time` = 当日 00:00（上海） | 盘前筛选、日线回测、基准 |
| 1 分钟线 | `market_data` freq=`1m`，`bar_time` = K 线**开始**时间（09:30 … 14:59） | 分钟回测撮合 |
| 复权因子 | `market_data.adj_factor`（后复权因子） | 决策日复权、除权入账 |
| 交易日历 | `trade_calendar` | 区间内缺任何一天就拒绝任务 |
| 历史名称 | `stock_name_history`（新表，M01 从 Tushare `namechange` 采集） | 当时是否 ST、当时名称 |
| 基准 | `market_data` 中 `000300.SH` 日线 | 沪深 300 对比 |

规则：

- **股票池**：区间内（含回看期）有日线的 A 股代码。`ashare.IsAStock` 判定：沪市 60x/68x，深市 00x/30x，北交所 4xx/8xx/92x。指数、B 股不进池。不读 `stock_basic`，因此已退市的股票不会被漏掉。
- **停牌**：某日没有该股日线即视为当日停牌。盘前判断用前一交易日状态（当日是否停牌在盘前不可知），当日停牌的委托在撮合时作废。
- **ST**：`stock_name_history` 中覆盖当日的名称含 `ST` 即为 ST。表为空时按非 ST 处理，报告写警告「缺少名称史，ST 判定可能偏乐观」。
- **市场截面**：前一交易日收盘后，用全池日线算涨停家数、跌停家数、炸板家数、上涨家数、下跌家数。盘中不更新。

数据载入：日线按区间（含回看期，默认 60 个交易日）一次读入内存。分钟线按交易日、只为当日候选和持仓读取，读过的放在进程内缓存，参数搜索多次运行共用。

## 3. 时钟与成交

### 3.1 分钟回测

每个交易日：

1. **盘前（09:25）**：处理除权（第 4 节）；为每只股票构造盘前快照（日线截至前一交易日）；`Filter` 通过的按 `Score` 降序（同分按代码）取前 `max_candidates`（默认 100）只；持仓股总在候选里。
2. 载入候选和持仓的当日分钟线。当日所有分钟时间点取并集，按时间排序。
3. 对每个分钟 m：
   1. 先撮合**上一分钟收盘后**生成的委托：用该股在 m 分钟的 K 线（若该股 m 分钟无 K 线，等到它当日下一根）。
   2. m 分钟 K 线走完（时刻 m+1 分钟），按代码顺序为候选和持仓构造快照：持仓且可卖数量 > 0 调 `ExitPlan`；未持仓、无挂单、且持仓数 + 挂单数 < `max_positions` 时调 `EntryPlan`。同一股票同一时刻最多一张委托，卖出优先。
4. 当日最后一根 K 线之后生成的委托作废，原因「收盘作废」。不隔夜挂单。
5. 收盘：用不复权收盘价逐股估值，记一条权益点；`RollDay` 使当日买入变为可卖。

11:29 那根生成的委托在 13:00 那根撮合。每张委托只有一次撮合机会，没成交（价格不到、封板、量不够）就作废，策略可在下一分钟重新给出。

### 3.2 日线回测

信号在当日 15:00 用含当日的日线生成，下一交易日用那天的日线撮合（开盘价成交）。下一交易日停牌则作废。超短线策略默认必须跑分钟回测，日线只做粗筛。

### 3.3 撮合规则 `sim.Match`

输入：方向、数量、限价（0 = 不限）、成交 K 线的开高低量、当日涨跌停价、规则参数。

| 情形 | 买入 | 卖出 |
|------|------|------|
| 无成交量或停牌 | 不成交「停牌或无成交」 | 同左 |
| 整根封死 | `Low ≥ 涨停价`：不成交「涨停封板」 | `High ≤ 跌停价`：不成交「跌停封板」 |
| 成交价 | `Open + 滑点`，再限制在涨跌停之间 | `Open − 滑点`，再限制在涨跌停之间 |
| `limit_fill=never` | 成交价等于涨停价就不成交「涨停不排队」 | 成交价等于跌停价就不成交 |
| 限价 | 成交价 > 限价：不成交「价格未到」 | 成交价 < 限价：不成交 |
| 成交量上限 | 最多该 K 线成交量 × `volume_cap`（默认 10%），再按手数向下取整；为 0 则「量能不足」 | 同左；非科创板按 100 股取整，除非一次卖完全部可卖 |

`limit_fill` 默认 `opened`：只要这一分钟最低价低于涨停价就认为打开过、能买到。分钟线看不到排队，这个口径会高估打板成交率；要保守时选 `never`。报告里写明用的是哪种。

其余默认值：滑点 1 个最小价位；佣金万 2.5、最低 5 元；卖出印花税万 5；过户费万 0.1。全部来自任务参数，不写死在逻辑里。

买入数量按板块取整：主板、创业板 100 股整数倍；科创板 200 股起。当日买入的数量不进可卖，下一交易日开盘前才可卖（`sim.Book`）。

成交时再核一次资金：成交额 + 费用超过可用资金时，按手数缩到买得起；缩到 0 则「资金不足」。

## 4. 复权与除权

- **策略看到的日线**：按决策日复权，`价格 × f(当根) / f(决策日)`。决策日的因子取当日 K 线上的因子（除权在盘前已公告）；当日停牌则取最近一根的因子。
- **当日分钟线、撮合、估值**：一律用不复权价。当日分钟线与复权后的日线在同一基准上。
- **涨跌停**：以除权参考价为前收，`前收 × f(前一根) / f(当日)`，再按板块幅度用 `ashare.Limit` 算。
- **持仓跨除权日**：持有 q 股、前收 P、因子 f0 → f1 时，按 `q × P × (1 − f0/f1)` 记入现金，视为分红送转的等值收益，并计入该回合盈亏。股数不变。这是近似处理，报告写明。

## 5. 策略接口 `pkg/rules`

回测和实盘用同一份 `Strategy`：`Name / Filter / Score / EntryPlan / ExitPlan`。引擎只把 `Snapshot` 交给策略，`as_of` 及之前的数据才在里面。

```go
type Snapshot struct {
    Symbol, Name string
    ST, Suspended bool
    ListDate time.Time
    AsOf     time.Time   // 决策时刻
    Bars     []Bar       // 已收盘日线，不含今天，决策日复权
    Today    *Bar        // 当日已走完的部分，不复权；还没有则为 nil
    Stage    Stage       // 截至 AsOf 的情绪阶段，缺数据时为 WARM
    NegativeNews bool    // 回测恒为 false
}
type Position struct { Symbol string; Quantity, Available int; AvgCost, StopLoss, TakeProfit float64; HoldDays int }
```

注册表：`ParamSpec`、`Spec`，`Register` / `Find` / `List`。`Spec.Resolve` 补默认值并检查范围。`Spec.ParamKey` 是参数在 `strategy_config` 里的键：`breakout_ref` 用 `<策略>.<参数>`；M06 两个模板用 `m06.fb.*` / `m06.pd.*`，价格参数用 `m06.stop_atr` 这类不带模板前缀的键。

M06 的 `first_board_weak2strong`、`pullback_dip` 已在 `pkg/rules` 注册，并实现 `BuyLevels`：下单决策时按实盘同一套 `PriceParams.Buy` 算买入限价、止损、止盈，写进持仓供 `Exit` 使用。算不出价位就放弃这笔。

**仓位**：`Plan.Shares > 0` 用策略给的股数；为 0 时按「当前权益 × position_pct（默认 20%）」折算。`Plan.Price > 0` 是限价；M06 模板的限价改用 `BuyLevels` 的入场上沿。

**参考策略 `breakout_ref`**（只用于验收引擎，在 `pkg/rules/refstrat`）：

| 参数 | 默认 | 范围 / 步长 |
|------|------|-------------|
| lookback 突破回看天数 | 20 | 5–60 / 5 |
| stop_loss 止损比例 | 0.05 | 0.02–0.10 / 0.01 |
| take_profit 止盈比例 | 0.10 | 0.04–0.20 / 0.02 |
| max_hold 最长持有交易日 | 3 | 1–10 / 1 |
| min_amount 近 5 日日均成交额（元） | 1e8 | 5e7–5e8 / 5e7 |

- Filter：非 ST、非停牌、日线够 lookback 根、近 5 日日均成交额达标。
- Score：最新收盘 / 前 lookback 日最高价，封顶 100。
- Entry：当日已有 K 线、最新价突破前高且低于涨停。限价 = min(最新价 × 1.01, 涨停价)。
- Exit：跌破成本 × (1 − stop_loss) 止损；高于成本 × (1 + take_profit) 止盈；持有满 max_hold 天且 14:50 之后时间止损。

## 6. 指标口径

| 指标 | 口径 |
|------|------|
| 累计收益 | 末日权益 / 初始资金 − 1 |
| 年化 | (1 + 累计)^(252 / 交易日数) − 1 |
| 最大回撤 | max((峰值 − 权益) / 峰值)，记峰值日和谷底日 |
| 夏普 | 日收益均值减 `rf/252`，除以日收益样本标准差，乘 √252。`rf` 默认 0 |
| 卡玛 | 年化 / 最大回撤 |
| 胜率 | 盈利回合 / 已平仓回合。盈亏为 0 算不盈利 |
| 盈亏比 | 平均盈利回合金额 / 平均亏损回合金额的绝对值 |
| 期望 | 每回合平均收益率（回合盈亏 / 回合买入额） |
| 换手（年化） | (买入额 + 卖出额) / 2 / 平均权益 × 252 / 交易日数 |
| 平均持仓天数 | 回合首笔买入到末笔卖出相隔的交易日数 |
| 分年 | 每个自然年的收益、最大回撤、回合数 |
| 基准 | 沪深 300 收盘价按首日前收归一到初始资金；超额 = 累计 − 基准累计 |

回合盈亏 = 卖出额 − 买入额 − 全部费用 + 除权入账。区间结束时未平仓的持仓按最后收盘价计入权益，但不计入回合统计，报告单列。

## 7. 未来函数防护

两层：

1. **结构**：策略只拿到第 5 节的 `Snapshot`，由引擎统一按 `as_of` 截断。数据可以超前读进内存，但不会出现在视图里。
2. **截断自检**（任务参数 `lookahead_check`，单次回测默认开）：取区间中点为切点日 T。第二次运行把 T 及之后每根 K 线的价格乘一个随机系数（0.8–1.2，按股票和日期固定种子）、成交量打乱。比对 T 之前的全部成交和每日权益，必须逐项相同。不同即失败，报告给出第一处差异。

## 8. 参数搜索、样本外、前推

- **空间**：每个参数取 `Min..Max` 内、按 `Step` 的格点（可由任务缩小范围）。
- **网格**：笛卡尔积，超过 `max_runs`（默认 200）拒绝。**随机**：按种子抽 `max_runs` 个格点，去重。
- **目标**：`sharpe`（默认）/ `annual` / `calmar`。回合数少于 `min_trades`（默认 20）的点记为无效。
- **样本内外**：前 70% 交易日搜索，最优点在后 30% 再跑一遍。样本外目标值低于样本内的一半、或样本外收益 ≤ 0，标「样本外衰减」。
- **滚动前推**：训练窗 `train_days`（默认 120）、测试窗 `test_days`（默认 40），按测试窗步进。每窗在训练窗搜索、在测试窗验证，拼接测试窗权益得到前推指标。
- **过尖**：最优点的相邻点（某一维差一个步长；随机搜索取归一化距离最近的 2×维数个点）目标值中位数 < 最优值的 50%，标「过尖」。
- **不敏感**：全部有效点目标值的极差 < 最大绝对值的 5%，标「不敏感」，说明参数基本不起作用。

## 9. 蒙特卡洛

单次回测结束后自动算。对日收益做分块重采样（块长 5 日，默认 1000 次，种子随任务固定），每次拼出与原区间等长的序列，统计累计收益和最大回撤的 5% / 50% / 95% 分位、亏损概率、回撤超过准入阈值的概率。

## 10. 任务

```
queued → running → succeeded
                 → failed
                 → cancelled
```

1. 客户端提交：类型（`single` / `optimize` / `walkforward`）、策略、参数、频率、起止日、初始资金、基准、撮合参数、搜索参数、种子。
2. 服务写 `backtest_task`：配置 JSON、参数哈希、引擎版本、构建版本，状态 `queued`。
3. 工作协程（默认 1 个，可配）按 id 顺序认领：条件更新 `queued → running`，只有一个能成功。
4. 每完成一个交易日回调进度；每秒最多写一次库，并向 NATS `backtest.progress` 发一条（普通 NATS，不进流）。客户端每 2 秒轮询兜底。
5. 取消：排队中直接置 `cancelled`；运行中通过 context 取消，引擎在下一个交易日检查。
6. 结束：同一事务写 `backtest_trade`（每笔成交）和 `backtest_report`（指标、权益、分年、最差 5 回合、警告、自检、搜索、蒙特卡洛、数据哈希、成交哈希）。
7. 服务启动时把遗留的 `running` 置为 `failed`「服务重启中断」。
8. 重跑：复制配置新建任务；报告里与原任务比对数据哈希和成交哈希，写「复现一致 / 数据已变 / 不一致」。

## 11. 前向影子（大模型不进历史回测）

模型训练语料里已经有历史上的新闻和涨跌，让它「回到 2023 年」选股会偷看未来。所以回测引擎只跑确定性规则策略，模型从上线之日起记影子。

- 定时任务 `backtest.shadow`（交易日 16:00）：把 `agent_decisions` 里 `symbol` 非空、未丢弃的新研判写入 `shadow_signal`（按研判 id 去重），再为未完成的行补收益。
- **参考价**：研判时刻之后第一个开盘的交易日的开盘价。09:30 前做的研判用当日开盘，盘中或收盘后做的用下一交易日开盘。
- **收益**：参考日记为第 1 日，`ret_tN` = 第 N 个交易日收盘 / 参考价 − 1。数据不够的先留空，以后补。
- **统计接口**：按模型、提示词版本、区间过滤；给出各周期的样本数、平均收益、胜率，以及评分五档（0–20 … 80–100，置信度 ≤ 1 时先乘 100）的平均收益，用于看评分是否单调。

评价模型只用这段前向记录，不用回测曲线。

## 12. 自省与参数进化

### 12.1 每日自省（交易日 15:30，`backtest.introspect`）

输入（都只读 `strategy_candidates`，M06 在 15:40 回填 `ret_t1/3/5`，所以当天自省用的是截至前一交易日、后验已经补上的样本）：

| 项 | 来源 |
|----|------|
| 胜率、平均收益 | 近 30 个交易日 `stage = selected` 且配置的收益周期（默认 T+3）已有值的行。收益 > 0 算赢 |
| 漏选 | 同期没入选、原因是 `not_in_ai_top` / `below_threshold` / `daily_cap` / `ai_invalid`，且该周期收益 ≥ 5% 的行 |
| 错误归因 | 亏损的入选样本，按落库事实依次判断：信号 `expired` / `rejected` / `cancelled` 为 `unfilled`；当日情绪为冰点或退潮为 `emotion_mismatch`；卖出原因是利空或消息面分 ≥ 70 为 `news_misread`；其余为 `indicator_failed`。漏选记 `missed` |
| 回撤 | 同期 `account_snapshots`（book 默认 `paper`）每个交易日最后一条权益 |

归因写回 `strategy_feedback`（`attribution` 默认空，另加 `strategy` 便于按策略覆盖）。每个交易日每个 book 写一行 `introspection`，重复执行覆盖。

**触发**：最近 5 个交易日的自省行胜率都低于 40%，且每行样本数 ≥ 10。阈值可配。15:30 跑的时候当天后验通常还没回填，触发看的是已经写好的自省行。

### 12.2 进化提案

触发后，对配置里的在用策略：

1. 读当前生效参数（`strategy_config` 中 `<策略名>.<参数名>` 的键，没有的取默认值）。
2. 生成有界候选：每个参数在当前值上下各一个步长内取值（不超出 `Min..Max`），按日期种子最多抽 20 组。
3. 建一个 `evolve` 任务：在样本内窗（默认样本外窗之前的 120 个交易日）里选最优候选，再在样本外窗（默认最近 60 个交易日）分别跑当前参数和最优候选。
4. 最优候选在样本外的目标值高于当前参数、且回合数达标时，写 `param_proposal`（`pending`）。否则不出提案，自省行里写原因。

### 12.3 批准与回滚

- 批准：用 `params.PutMany` 一次写入全部键并生成一个新的生效版本，记下批准前的生效版本号。提案置 `approved`。
- 拒绝：置 `rejected`，参数不动。
- 回滚：取该策略最近一次 `approved` 的提案，`params.Rollback` 到它记下的上一版，提案置 `rolled_back`。没有上一版就报错。注意 `strategy_version` 是全局快照，回滚会恢复全部参数键。
- M11 要求这些操作限 Owner 并写 `audit_log`。M11 完成前，接口记下请求头 `X-User`（缺省 `local`），作为技术债登记。

## 13. 周报、月报

接口按需生成，不落表：周期内的自省胜率走势、各 book 权益变化与最大回撤、影子统计、完成的回测任务、提案的创建和处理。周以周一为始，月以自然月。

## 14. 准入检查表（FR-07-11）

| 项 | 判定 | 数据 |
|----|------|------|
| 回测达标 | 该策略最近一次成功的单次回测满足：回合数 ≥ 30、最大回撤 ≤ 20%、年化 > 0、盈亏比 ≥ 1.2、夏普 ≥ 0.5 | `backtest_report` |
| 未来函数自检 | 上面那次回测的自检通过 | 同上 |
| 样本外 | 该策略最近一次 `optimize` 或 `walkforward` 任务没有「样本外衰减」 | 同上 |
| 模拟盘满 20 个交易日 | `account_snapshots` book=`paper` 覆盖的交易日数 ≥ 20 | 账户快照 |
| 模拟盘回撤 | 模拟盘期间最大回撤 ≤ 10% | 账户快照 |
| 风控演练 | 熔断、Kill Switch、行情中断、终端扫单停止 | M08 尚无记录，显示「需人工确认」 |
| 东财文件单联调 | 仿真账户买入、撤单、卖出各一笔 | M09 尚无记录，显示「需人工确认」 |

每项为 `pass` / `fail` / `unknown`。全部 `pass` 才算可以进入半自动实盘。阈值都在配置里，**默认值需要你确认**。

## 18. 客户端回测页

路由 `/backtest`，四个页签：

1. **任务**：新建表单（策略、参数、区间、频率、资金、撮合参数、类型），任务列表（状态、进度、取消、重跑）。
2. **报告**：指标卡、权益与沪深 300 曲线（ECharts，可缩放；盈利区绿、回撤区红）、回撤曲线、分年表、最差 5 回合、成交明细、警告、自检、参数搜索结果、蒙特卡洛分位。
3. **进化**：影子统计、自省记录、提案列表（批准 / 拒绝）、回滚按钮。
4. **准入**：检查表与周报、月报。

## 19. 和模拟盘、实盘的关系

| 阶段 | 做什么 |
|------|--------|
| 回测通过准入阈值 | 才允许该策略版本进入模拟盘 |
| 模拟盘满 20 个交易日且指标、风控演练通过 | 才允许 L2 实盘 |
| 实盘之后 | 继续记影子和真实成交，和回测偏差过大就降级 |

回测好看但模拟盘对不上，以模拟盘为准，并在报告里写明偏差来源（滑点、封板、数据缺失）。
