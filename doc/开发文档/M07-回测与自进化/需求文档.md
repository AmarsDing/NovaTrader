## 1. 要回答的问题

一条策略在过去一段行情里：赚多少、最大亏多少、胜率多少、盈亏比多少、亏在什么规则上。结果必须能用同一段数据和同一套参数重跑出来。

## 2. 名词

| 名词 | 含义 |
|------|------|
| 可见时刻 `as_of` | 一根 K 线走完的时刻。1 分钟线 = `bar_time` + 1 分钟；日线 = 当日 15:00。策略在时刻 t 只能看到 `as_of ≤ t` 的数据 |
| 决策日复权 | 历史价格乘以 `adj_factor(当根) / adj_factor(决策日)`。不用「最新因子」的前复权，因为那会用到决策日之后才公布的除权 |
| 回合 | 一只股票持仓从 0 变正、再回到 0 的全过程。胜率、盈亏比都按回合算，不按单笔成交算 |
| 策略版本 | 策略名 + 参数。参数的哈希写进任务，作为报告里的「策略版本」 |
| 数据版本 | 本次任务实际读到的全部 K 线、名称史按固定顺序算出的 SHA-256 |
| 前向影子 | 模型研判上线后，每条研判在之后 T+1 / T+3 / T+5 的真实收益 |

## 4. 验收

| # | 验收项 | 怎么验 |
|---|--------|--------|
| 1 | 同一输入重跑，成交明细一致 | 重跑任务的数据版本相同时，成交哈希必须相同 |
| 2 | 手工推演 | 单元测试里至少 3 笔与手算逐笔一致：涨停封死买不进、T+1 当日不能卖、费用（含 5 元最低佣金和印花税） |
| 3 | 未来函数自检 | 在切点日之后把数据打乱后重跑；切点日之前的每笔成交和每日权益必须完全相同。任何不同即判定失败，报告标红 |
| 4 | 不可回测时拒绝而不是猜 | 区间内交易日历有缺日、或没有任何行情时，任务失败并写明原因 |
| 5 | 提案不自动生效 | 参数进化只写提案；批准后 `strategy_version` 才切换；回滚后参数恢复到上一版 |
| 6 | 真实数据跑通（MVP 完成标志） | 选一段真实历史分钟线跑通一个策略，报告能在客户端打开。依赖 M01 分钟线入库，见开发进度 |

## 5. 不在本模块承诺的事

- 年化 30%、回撤 20%、胜率 55%、盈亏比 1.5 是目标，不是回测器的交付保证。达不到时，系统应如实出报告，而不是调参到「看起来达标」。
- M06 的两个策略模板由 M06 实现。M07 自带一个确定性参考策略 `breakout_ref`，只用来验收引擎，不用于实盘。
- 盘中全市场分钟级情绪截面不进本版（体量太大）。策略拿到的市场截面是前一交易日收盘后的统计。
- 行情、名称史、交易日历的采集属于 M01。本模块只读这些表，缺了就在报告里写明。

## N4-01 不可变研究输入（2026-10-16）

新任务排队前冻结 manifest_id/hash；重跑不得重新读取可变行情。缺 available_at 的历史行、09:25 前未知的证券状态或当日复权、晚到修订显式列排除原因，不再按非ST/默认复权或当前股票池补齐。报告同时显示完整 manifest 身份与原引擎 DataHash/FillsHash。无合格数据必须失败。实现与外部依赖见 [N4-01 实施记录](../实施记录/N4-01-PIT与冻结数据集-2026-10-16.md)。

## N6 独立研究工具（2026-10-16）

QuantStats 必须接同一费用后账户 NAV、初始点、显式对齐基准和现金流政策；组合优化仅交影子权重，须处理现金/行业/单股/锁仓/换手及不可行情形。研究文件必须绑定不可变 manifest 并保留完整输入/环境/产物指纹。vectorbt 必须许可和固定版本 opt-in；RD-Agent 只允许隔离离线作业，不持交易能力。缺包或缺历史证据应明确 unavailable/unknown。CLI 和核心两库已实际验证，Go 调度/正式 NAV 导出/候选晋级仍待接入；见 [N5/N6 记录](../实施记录/N5-02-N6-研究适配-2026-10-16.md)。

## N5-03 前瞻预测证据（2026-10-16）

固定目标、时间起点、期限、费用/T+1 与成交标签边界，先归档再评价。原预测不可覆盖，真实 prospective 和 synthetic 不得混用。数据或成交未知不能补零；样本/校准不足时概率与 Brier/ECE 保持 null。生产展示与自动交易仍不开放。已落地的文件协议和 6 项新增验证见 [N5-03 记录](../实施记录/N5-03-预测归档与离线评价-2026-10-16.md)。
