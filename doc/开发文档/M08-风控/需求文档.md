# M08 风控 · 需求文档

| 模块 | M08，服务 `risk`，纯规则在 `pkg/risk` | 版本 v0.3（2026-10-08 评审后修订） |
| 原则 | 任何订单，包括手动单和卖出单，都先过风控。风控超时视为拒绝。缺数据时开仓按拒绝处理，卖出尽量放行。 |

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-08-01 | 事前规则按固定顺序执行，一条拒绝即停止 | P0 |
| FR-08-02 | 默认单票 ≤5%、总仓 ≤80%、同板块 ≤30%、当日亏损 2% 停止开仓 | P0 |
| FR-08-03 | 仓位上限随风险度和情绪阶段缩小（系数表见设计文档第 4 节） | P0 |
| FR-08-04 | 持仓盯盘：止损、止盈、移动止盈、时间止损、指数急跌、突发利空 | P0 |
| FR-08-05 | 当日亏损达阈值后，收盘前只允许卖出 | P0 |
| FR-08-06 | Kill Switch：停止新单、撤销未成交、模式降到 L0。状态落库，重启后保持。恢复必须人工确认 | P0 |
| FR-08-07 | 指数大跌或炸板率过高时禁止开仓 | P1 |
| FR-08-08 | 行情延迟超过阈值时禁止自动单 | P0 |
| FR-08-09 | 每次校验留下规则、结果和输入快照 | P0 |
| FR-08-10 | 委托速度和每日申报撤单笔数设硬上限，低于程序化交易高频认定线（每秒 300 笔、每日 20000 笔） | P0 |
| FR-08-11 | 日度风险报告 | P2 |
| FR-08-12 | 规则参数热更新并记审计 | P1 |
| FR-08-13 | 运行模式 L0–L3 由风控保存，实盘模式要求准入已通过 | P0 |

R07–R12 只管买入；卖出直接放行。R10 与 R14 不同：R10 是策略层面的每日开仓笔数，R14 是申报加撤单的硬上限。

## 交易所规则（2026-10-08 核对）

| 项 | 主板 | 创业板 | 科创板 | 北交所 |
|----|------|--------|--------|--------|
| 涨跌幅 | 10%（ST、*ST 自 2026-07-06 起也是 10%） | 20%（含 ST） | 20%（含 ST） | 30% |
| 连续竞价价格笼子 | 基准价 ±2% 与 ±10 个价位取宽 | 同主板 | 基准价 ±2%，无 10 价位兜底 | 基准价 ±5% 与 ±10 个价位取宽 |
| 买入数量 | 100 股整数倍 | 100 股整数倍 | ≥200 股，可逐股 | ≥100 股，可逐股 |
| 单笔限价申报上限 | 100 万股 | 30 万股 | 10 万股 | 100 万股 |
| 卖出余股 | 不足 100 股的部分一次卖出 | 同主板 | 不足 200 股时一次卖出 | 不足 100 股时一次卖出 |

上市前 5 个交易日不设涨跌幅，风控默认不允许买入。

## 验收

- 上述规则有单元测试，覆盖主板 10%、主板 ST 10%、创业板/科创板 20%（含 ST）、北交所 30%、科创板 200 股、北交所逐股、各板价格笼子、T+1 可卖量、余股卖出。
- 缩量放行时，返回的数量是合法手数，并写明原因。
- Kill Switch 触发后重启服务，状态仍为已触发。
- `CheckOrder` 本机 P99 ≤ 50 毫秒。
