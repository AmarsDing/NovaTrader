# M05 AI 智脑 · 需求文档

| 模块 | M05，服务 `brain` | 版本 v0.3 |
| 硬界限 | 模型只产出评分、理由和证据编号。价格、仓位、是否下单由规则和风控决定。 |

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-05-01 | 统一调用本地 vLLM。按任务选大模型或小模型。排队、超时、失败后退回纯规则分 | P0 |
| FR-05-02 | 技术、消息、资金、外围/情绪四个维度各给 0–100 分和理由 | P0 |
| FR-05-03 | 输出必须符合 JSON。校验失败重试一次，再失败则丢弃该候选 | P0 |
| FR-05-04 | 价格和指标由系统写入提示词。模型不得自报数字。输出里的数字要能在输入里找到 | P0 |
| FR-05-05 | 每条理由引用情报或因子 ID | P0 |
| FR-05-06 | 盘前晨报，5 分钟内 | P0 |
| FR-05-07 | 持仓或候选异动解读 | P1 |
| FR-05-08 | 每次调用留下模型版本、提示词版本、输入摘要、耗时 | P0 |
| FR-05-09 | 提示词版本化 | P1 |
| FR-05-10 | 向客户端推送研判阶段进度 | P1 |
| FR-05-11 | 针对已有信号追问 | P2 |
| FR-05-12 | 推理延迟和显存占用可查询 | P1 |

FR-05-01 与 FR-05-03 的区别：

- **模型不可用**（连接失败、超时、排队满、熔断中）：返回规则分，标记 `ai_degraded`。候选保留。
- **模型可用但输出不合格**（JSON 结构错、证据 ID 不在事实包、数字对不上）：带上错误原因重试一次，仍不合格则丢弃该候选，标记 `discarded`。

FR-05-12 的「显存占用」取 vLLM `/metrics` 中的 KV 缓存占用率。物理显存需要在 DGX 上读 `nvidia-smi`，归 M11 运维聚合。

验收：单只候选完整研判 ≤ 30 秒（以实测为准）。全市场扫描时只把规则筛出的前 30 名送进模型，批量接口超过 30 只直接拒绝。
