### 1.3 结论先读

1. 重点视频里的产品是**长桥（Longbridge / LongPort）桌面专业终端**，界面右上角明确标 `LongbridgeAI`，账户头标 `Demo A/C(1757)`，交易按钮标 `Simulated Buy`——整段是模拟盘演示，不是实盘证明。
2. **终端 UI 本体闭源**，GitHub 上没有它的前端代码，不能"复制过来"。能合法学习的是：交互模式（抄思想不抄素材）+ 开源数据/交易 SDK（Apache/MIT）的数据合同与架构分层。
3. 其开源 SDK 对 NovaTrader 没有直接接入价值（行情仅限长桥账户港美股），但它的 **Context 分域、推送合并 store、静态/快照/计算指标三层、AI screener 条件模型、订单合同** 是我们自建通达信链路时第一手可抄的标杆。

## 3. 页面形态拆解（九种）

1. **市场总览页**：「指数卡 + 异动流 + 行业/概念列卡 + 行情榜多标签」四区块纵向滚动；市场切换（US/HK/CN/SG）和视图切换（Market/Sector/Heatmap）是最顶端两级导航。
2. **热力图**：板块嵌套 treemap，块面=市值、颜色=涨跌；悬停气泡给公司身份；粒度筛选在右上。
3. **自选列表**：一屏尽量多行，列可配；行即入口（点击=换证券，不重排布局）。
4. **多图盯盘**：3×3 tile 视图 + 右侧固定摘要栏；是专业模式，不是默认首页。
5. **个股详情页**：七页签（Chart/Options/Financial/Forecast/Valuation/Shareholder/Wiki）共享「右行情栏 + 底交易条」两层骨架；Financial 再嵌七子页签；任何图表可 `Zoom In` 单图全屏，退出即还原。
6. **右侧行情侧栏**（全站恒随当前 symbol）：报价头卡（最新价/涨跌/交易时间戳/市场旗/提醒铃/收藏心）→ 两列字段网格 → Bid/Ask 比例条 → Order Book → Time & Sales → Transaction Statistics 仪表盘 → Quotes/News/Wiki 页签。
7. **底部交易条**：子页签 `Trade/Today's Orders/Past Orders/Grid Trading/Holdings`；表单= Symbol/Type/B·S/Price/Quantity/Time in force + Buy on Cash&Margin 预估 + Attached order（止盈止损附加单）；期权单带 `P/L at expiration` 损益图与四值；成交用右上 toast 确认。图表区有独立 `Trading` 开关可整条隐藏。
8. **LongbridgeAI**：三态——图表侧 dock 面板 / 独立整页 / 结果回链证券；问候+建议问题+Shuffle；流式「thinking→解释→结构表→展望与风险」；左会话历史按 Today/Earlier 分组；独立页底部有指数快讯条。
9. **图表工具箱**：周期条（5D/D/W/M/Q/Y + 1min~1h）、Split-Adj 复权切换、画线（趋势线/形态）、文本批注、B/E/D 事件标记（买/财报/除息）、Trading 显隐、全屏。

## 4. 页面搭建与操作思想（提炼为设计原则）

1. **证券上下文是唯一主轴**。一切面板随当前 symbol 联动（右栏、底条、AI、新闻、图表同换），切证券不换布局。减少重复输入是这个产品最突出的体感来源。
2. **固定骨架 + 中部替换**：左轨道/顶页签/右栏/底交易条常驻，注意力只跟着中部主区走——总览→详情→AI/新闻→返回，位置记忆零成本。
3. **密度分层**：总览页求密（一屏多榜）、详情页求深（一屏一事）、表格页可配列；专业视图（九宫格/链矩阵）是可选模式而非默认。
4. **AI 是一等公民，但交付物必须结构化**：问句进来，表格/要点回去，且表格行可回链到证券页；聊天永远带上下文入口（建议问题、@提及、附件）。
5. **每个操作给即时可见的反馈**：`It is thinking` 流态、行悬停高亮、`Filled` toast、模拟/实盘标识（Simulated Buy、Demo A/C）常显——用户永远知道系统听见了。
6. **同区多维度切换而非多页跳转**：Market/Sector/Heatmap、Quotes/News/Wiki、今日订单/历史订单——同级信息在同一容器内换维度，不新开页面。
7. **单语义色高对比深色底**：全片只有"涨/跌"两族语义色（美股绿涨红跌）+ 品牌青点缀；数字与表格区域干净无光晕，光效只用于反馈与强调。

## 5. 其余四段视频要点（摘要，细节见 10-14 文档）

- **jev-cascade-02（26s）**：节点图+门槛（`gate ≥ 0.85`/`human · publish`）+ 底部四区终端带（代码/RUN LOG/NODE LOAD/GRAPH COST）。借取：NovaTrader 监控画布的 Gate 节点要显示**具体阻断原因与下一步**。
- **Five dots（16s）**：五 Agent 看板，按角色列「触发方式/JOB/RULE/ACTIVITY/是否待批准」，REVIEW+SIGN OFF 区+全天时间线。借取："谁在做什么、由什么触发、下一步谁决定"进监控详情。
- **Grok Bot（11s）**：GPU 租赁/token 路由看板，approve/deny 浮层。借取：模型路由、吞吐、预算/费用分区 + 变更预览与回执。
- **SPIDERORB（6s）**：情报筛选漏斗 + Decision Stack（SAVE/SKIP/BLOCK）+ LIFE OF A DECISION。借取：情报漏斗每步显示"减少了多少信息、为什么"，决策生命线可回溯。

## 6. GitHub 开源结果与可借用清单

- 终端 UI 本体（图标、品牌、配色组合、页面编排像素稿）——闭源且商标保护；热力图公司 logo 图、板块美术图等素材不可复制。

### 6.3 对本项目无直接接入价值的原因

行情与交易都绑长桥账户（美/港/新/A 股通），NovaTrader 决策 3 已定：行情走通达信、下单走东方财富文件单。**不引入 longport SDK 进依赖树**，只把上述合同与分层翻译成我们自己的 proto/schema。

## 7. 视频侧栏字段 ↔ SDK ↔ NovaTrader 数据源映射

| 视频右栏字段 | longport SDK 出处 | NovaTrader 落点（通达信/pyworker 或规则计算） |
|---|---|---|
| 最新价/涨跌/涨幅/交易时间戳 | `SecurityQuote{LastDone, Timestamp}` + `TradeStatus` | 已有快照字段 + 交易时段标签 |
| Open/High/Low/Prev Close、Volume/Turnover | `SecurityQuote` 同名 | 通达信日线/分时齐备 |
| Amplitude 振幅 / Turnover Ratio 换手 / Volume Ratio 量比 | `CalcIndex{Amplitude, TurnoverRate, VolumeRatio}` | 换手需流通股本；振幅、量比规则计算（量比需 5 日均量） |
| Average Price 均价 | `IntradayLine.AvgPrice` (=Turnover/Volume) | 分时均价线，规则计算 |
| 52wk High/Low、52 周区间位置 | 视频右栏有此字段；本轮研读的 `SecurityCalcIndex`/`StaticInfo` 均**无**现成 52 周字段，应由 K 线历史自算 | 同样由本地 1 年日线规则计算（需日线缓存） |
| Mkt Cap / Float Cap / Shares / Shares Float | `StaticInfo{TotalShares, CirculatingShares}` × 最新价 | Tushare/AkShare 股本字段 × 最新价 |
| P/E TTM / Dynamic / Static、EPS 三档、P/B、BPS | `StaticInfo{Eps, EpsTtm, Bps}` + `CalcIndex{PeTtmRatio, PbRatio}`；P/E = 价 ÷ 对应 EPS | Tushare 财报季更；缺数据要显"未知"不推近似值 |
| Bid/Ask Ratio 条 | 右栏组件（值近 33/67 为委托比） | A 股五档委托量可加总计算 |
| Order Book / Time & Sales / 逐笔方向 | `SecurityDepth`、`Trade{Price, Volume, Timestamp, TradeType, Direction}` | 通达信五档+逐笔；方向标记按买卖盘规则 |
| Transaction Statistics 仪表盘 | `TradeStats` | 大中小单统计，通达信资金流字段候选 |
| 盘口异常/异动 feed | `AnomalyItem` | 自研异动规则（涨速/封单/撤单/放量）→ 盯盘异动卡 |

## 8. 对 NovaTrader 的设计指引

以下全部服从决策 1/3 与视觉规范；编号对应可在迭代中逐项验收。

### 8.1 工作台骨架：正式确立"五区合同"

```text
┌─────────────────────────────────────────────────────────────────┐
│ 轨 │ 顶页签区（个股容器：Chart/Financial/…/KB，记忆上次位置）        │
│ 道 │ ┌───────────────────────────────────┬───────────────────┐ │
│ 市 │ │                                   │ 4 右证券上下文栏    │ │
│ 场 │ │ 3 中央主区                         │ (quote-sidebar)   │ │
│ 自 │ │  当前页签内容 / 单图可全屏           │ 报价头卡·字段网格   │ │
│ 选 │ │                                   │ ⚖五档·逐笔·Tab     │ │
│ AI │ │                                   │ (恒随 currentSymbol)│ │
│ 铃 │ ├───────────────────────────────────┴───────────────────┤ │
│ 设 │ │ 5 底交易条 (trade-bar, 恒随+授权徽标, 禁 popout)         │ │
│    │ │ 下单/今委托/历史/条件计划/持仓 · 可买预估 · 风控预览      │ │
│    │ └───────────────────────────────────────────────────────┘ │
│    │ 状态带：模式(回放/实时)·数据时效·授权级别·最急事件              │
└────┴───────────────────────────────────────────────────────────┘
```

1. **左轨道**（已有面板入口）：市场总览、自选、决策台、AI、通知、设置——单字母/图标+文字气泡，当前项高亮。
2. **顶页签区**：个股详情容器（Chart/Financial/Forecast/Valuation/Shareholder/KB 按需），页签记忆上次位置。
3. **中央主区**：当前页签内容；任何图可单图全屏且能还原。
4. **右证券上下文栏**（新增常驻面板 `quote-sidebar`）：报价头卡（含市场旗/铃/心）→ 两列字段网格（§7 第一组）→ 买五卖五比例条 → 五档盘口 → 逐笔 → Tab：快讯/相关情报/Wiki（知识库）。**恒随"当前 symbol"store 切换**，任何面板可成为切换源。
5. **底交易条**（新增常驻面板 `trade-bar`，归 `trade` 组、禁 popout）：子页签 下单/今日委托/历史委托/条件计划/持仓；表单含品种/类型/买卖/价格/数量/有效期 + **可买数量预估** + 关联止盈止损；提交前强制显示授权状态（模拟/半自动/禁）与最近一次风控结论；回报用 toast（Filled/Rejected 带原因）+ 条内状态行。

### 8.2 新增/改造面板清单（对齐 21 面板注册表）

- 新增 `market-overview`（市场总览：指数卡+异动 feed+行业列卡+涨跌榜多标签）——对应 M02；异动模型按 §6.2 的 AnomalyItem 定合同。
- 新增 `quote-sidebar`、`trade-bar`（singleton、trade/settings/ops 列入禁弹白名单外）。
- `market` 行情面板：补"热力图"视图（板块 treemap 用 ECharts treemap；无 logo 素材，用文字 tile）。
- AI 助手面板（新 `nova-ai`）：三态（右 dock / 独立 center / 结果卡回链 symbol）；会话历史按 Today/Earlier 分组；输入支持 @证券 与附件（研报/截图以证据链入库）；流式协议要区分 thinking/解释/结构表块/展望四段；**结论永远以结构卡呈现（候选/依据/反证/有效期/来源），聊天只是入口**。
- 个股详情容器：在 `market` 演进为七页签容器；Financial 页等 M04/Tushare 财报字段齐备后排期，未接入页签显示"待接入"占位而非删页签。
- 图表工具：K 线组件补画线持久化（趋势线/形态）、文本批注、B/E/D 事件标记（B=策略买点、E=财报、D=除息，来自交易日历同步表）、周期条、复权切换、`Trading` 显隐底条。
- 期权：A 股无个股期权，**不复制期权页**；ETF 期权如需纳入另行立项。

### 8.3 交互规范（写入走查清单）

1. 全局唯一 `currentSymbol` store：切 symbol 只改数据不换布局；切换源（列表/AI 卡/信号票/热力图点击）要带 ripple 定位回跳。
2. 所有等待 >150ms 的远程调用有可见状态；AI 长任务必流式，且允许取消。
3. 买入/卖出/撤单/授权变更：先预览（影响+风控条款）→ 确认 → toast 回执 → 失败给原因与下一步；未知回报进入"待核"不静默。
4. 模拟/实盘身份常显（顶栏徽标 + 底条 Simulated 前缀），实盘授权多层确认按 N9 文档。
5. 密度：总览面板默认密（行高紧凑）、详情默认疏；专业视图（多图网格/全字段表）由用户显式打开且可保存为预设。
6. 视觉：语义色只用红涨绿跌+琥珀告警；玻璃/霓虹材质照视觉规范第七节用在 HUD/浮层/结论卡，密集数据区保持实底；数字等宽、列宽稳定。

### 8.4 数据合同先行（proto-first 对齐 §6.2）

- 行情快照 `SecurityQuote`、五档 `Depth`、逐笔 `Trade{…Direction}`、计算指标 `CalcIndex`（按需点菜式请求）写进 `backend/api/market/v1/`；
- 异动 `AnomalyItem`、榜单 `RankList` 写进 market 域；
- AI 选股四端点 + 条件模型 `{key,min,max,tech_values}` 写进 strategy 域；
- 订单 `Order/OrderHistoryDetail`、预估 `EstimateMaxPurchaseQuantity` 写进 trade 域（提交前预估必须服务端重算，前端只做展示）。
