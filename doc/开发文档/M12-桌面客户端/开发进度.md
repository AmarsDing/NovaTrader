### P1 缺陷（修复）

- **实盘 fail-open**：交易页 onMounted 直接把持久化账本写回选择器，watch 对原生 select 的 disabled 不设防——未满 20 交易日也可能以 LIVE 视图渲染。提交拦截保留，另在 watch 与 load() 各加一次「LIVE 且未准入 → 强制切回 SIM + hint」纠正。
- **面板参数送达断链**：`panel-bus` 只有挂载时 `consumePanelParams`，已打开面板收不到二次跳转参数（新闻→情报、板块/代码→行情、信号→交易全断）。panel-bus 增加 `onPanelParams` 实时投递（挂载直发 + 订阅推送，返回退订），情报/行情/交易三视图接通并统一走 `applyPanelParams`。
- **cancelAllTimer 泄漏**：一键全撤 8 秒臂态定时器在组件卸载时不清理；`onBeforeUnmount` 补 `clearTimeout`。
- **破板率单位错**：后端 `brokenRate` 是 0–1 比率（BrokenCount/(UpCount+BrokenCount)，配置阈值 0.40=40%），监控 HUD `Math.round(rate)%` 与场景卡 `toFixed(2)%` 都按百分点渲染（0.4 → 显示 0% 或 0.40%）。HUD/场景卡改 `ratioPct`；`hud.test.ts`/Gallery 夹具 41.2/32.4 改回 0.412/0.324。
- **misses 契约错**：`ScanReply.misses` 后端是 `map<原因代码, 只数>`，前端类型与渲染按 `map<代码, 原因>` 写反。`api/strategy.ts` + `api/types/strategy.ts` 类型改正，自选面板按「原因 → 只数」渲染（形状同 dropped），去掉不存在的代码点击跳行情。
- **影子均值单位**：监控终端带/场景卡把 `avgReturn` 当百分点直印，改 `ratioPct`。
- **信号状态漏译**：`pending`（待审核）不在 `SIGNAL_STATUS` 文案表，裸显示英文。已补。
