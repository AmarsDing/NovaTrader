## 〇、五条直觉（全单的北极星）

1. **先减后加**：每像素回答「帮读还是帮做」，装饰超发 = 注意力贬值。
2. **色彩是词汇表**：语义色 ≤5 词（涨跌方向 / 行动主色 / AI 紫 / 警告琥珀 / 休眠灰）。安静攒够了，关键时刻才配锋利——买 = 整块红、卖 = 整块绿、快捷键印在按钮上。
3. **层级靠明度台阶与字重台阶**（400/500/600/700），不靠边框发光。
4. **按任务组织视图**：每页第一眼回答「现在怎么样」+「所以我能干什么」，看与做同框。
5. **状态即同理心**：空 / 错 / 禁 / 载 / 缺先设计，界面每句话都要为真。

## 三、基件缺件单（B3 新件，按优先级）

1. **NtEmpty**——{icon, title, hint?, action?{label,panel|to}, state?:'loading'|'error'|'empty'} 三段式；收编 NtTable/NtTimeline/NtLadderTiers 的纯文本 empty prop 为 slot。
2. **NtErrorGuide**——{error, tone?, retry?, actions?[], context?}；把 alert-rules:182-186 三分态诚呈铸成组件，替换全仓 44 处裸 `nt-err` 红字（34 文件、15 处抽样无一给出路）。
3. **NtMissing**——{reason?} 渲「—」+title 原因，全仓 clock()/null 空白格收编。
4. **NtSkeleton**——{rows?,kind?} 替换「读取中…」裸文本（audit-trail/notify/TradeView/SignalView/kb-search）。
5. **NtConfirm 通用壳**——stores/confirm.ts 从订单专用抽通用（标题+后果文案+危险钮+可选倒计时）。
6. **NtButton.disabledReason + hero 尺寸档**——禁用给原因（QD：未回测禁发布给出原因与出路）；买卖整块色+快捷键徽注走 hero 档。
7. **viz 死件处置**：NtGauge/NtSparkline/NtHeatmap/NtIndicatorChart/NtDepthBoard/NtFunnel(+display 同名件） 生产零消费——接得上消费者的接（DepthBoard→quote-sidebar 替换手绘 ladder、Heatmap→大盘热力、Funnel→信号审核漏斗），接不上的下线出组件册。
