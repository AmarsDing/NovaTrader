# M12 桌面客户端 · 设计文档

版本 v0.4（P4–P6 落地后更新；P1 类型化基建、P2 视觉令牌与组件库、P3 dockview 工作台壳、P4 业务面板、P5 壳打磨、P6 工程化）。

技术：Vue 3 + Vite + vue-router + Pinia，桌面壳用 Tauri 2，`frontendDist` 指向 `../dist`。
K 线用 lightweight-charts，其余图用 ECharts（`echarts/core` 按需引入）。
布局用 `dockview-core`（**有意不用 dockview-vue**，自行接管 renderer 与主题）。

```text

├── ws/             topics.ts（主题与 payload 类型）+ hub.ts（连接、去重、动态订阅）+ __tests__

├── theme/          tokens.css（唯一色彩来源）+ tokens.ts（图表用 TS 镜像）+ dockview-theme.css

├── display/        NtStatCard/NtTimeline/NtFunnel/NtLadderTiers（业务展示件，无图表实例）
├── widgets/        ConfirmSheet、KillSwitchBar（跨页面业务件）
├── workspace/      工作台壳：DockHost/CommandBar/StatusBar/CommandPalette/AlertCenter/shortcuts/注册表

├── view/           P2 重铸的业务视图（被 panels 薄壳复用）
```

发光预算见 `1.视觉需求.md` 第五节：玻璃模糊只允许 CommandBar / 弹层 / AlertCenter，glow 只给 AI 高分信号、预警、Kill Switch。

## 2. 工作台（P3）

进 app 即工作台（`/`），登录页只作门禁（`/login` 挂 BlankLayout，不挂 dock）。

- `workspace/DockHost.vue`：`createDockview(el, { theme: ntTheme, className:'nt-dock', defaultTabComponent:'nt-tab', createComponent, createTabComponent, createWatermarkComponent })`。
  主题对象 `{ name:'nt', className:'dockview-theme-nt', colorScheme:'dark' }`。
- `workspace/vue-renderer.ts`：Vue ↔ dockview 桥。每个面板/标签页/水印各起一个子 Vue app，并把宿主 `appContext` 赋给它，
  因此面板内的 pinia / router / provide 与整机一致；`dispose()` 反挂载，关面板即释放 watcher 与 ECharts 实例。
- 自定义标签页 `workspace/PanelTab.vue`：标题 + 链路状态点 + 关闭；由 `defaultTabComponent` 显式打开这一分支
  （dockview 只在 `defaultTabComponent` 有值时才会调用 `createTabComponent`）。
- 空工作台水印 `workspace/DockWatermark.vue`：脉搏 + `Ctrl+K` 提示。

## 3. 面板注册表与打开方式

`workspace/panel-registry.ts`：`id → { title, icon, loader（懒加载分包）, group, singleton }`。
P3 注册 9 个既有页面，P4 追加 12 个业务面板，共 **21 个**：

| 组 | 面板 id |
|---|---|
| 既有页面 | overview 决策台 · signals 信号 · market 行情 · trade 交易 · intel 情报 · backtest 回测 · ops 运维 · settings 设置 |
| market | limit-ladder 涨停梯队（M02）· watchlist 自选扫描 |
| brain | morning-briefing 晨报（M05）· brain-monitor 模型链路（M05）· model-stats 模型统计（M05） |
| strategy | pool-manager 股池黑名单（M06）· evolution 影子进化（M07） |
| risk | risk-chain 风控链 R01–R15（M08）· risk-report 风控日报（M08） |
| notify | notify-center 通知中心（M10） |
| kb | kb-search 知识库（M04） |
| datahub | datasource-health 数据源治理（M01） |
| admin | audit-trail 审计日志（M11，配套后端增量见 §9） |

`panels/<组>/*.panel.vue` 是薄壳，真正逻辑在对应 widget/view；面板均懒加载分包（`loader: () => import(...)`）。

打开契约 `workspace/inject.ts`：

```ts
interface WorkbenchApi {
  openPanel(id, params?)          // 已开则聚焦，未开则落入当前组（within）
  captureLayout(): unknown        // api.toJSON()
  applyLayout(layout, {persist})  // 容错：非法结构回退默认预设
  resetToDefault()
  panels: PanelDef[]
}
```

参数传递 `workspace/panel-bus.ts`：深链/跳转方先 `stagePanelParams(id, params)` 登记，面板组件挂载时 `consumePanelParams(id)` 取一次。
之所以不走路由 query：深链打开后地址要剥回 `/`，query 会被清掉；路由 query 仍作为兼容兜底。
信号页「去下单」因此改为 `openPanel('trade', {symbol, side, price})`，不再是页面跳转。

## 4. 布局持久化与预设

`stores/layout.ts`：

- 主布局键 `nt.layout.v1.<accountId>`（accountId = 登录用户名，缺省 `local`），值 `{ version: 1, layout: dockview.toJSON() }`；
- `onDidLayoutChange` 防抖 500ms 写盘；程序化套用布局期间（`applying`）不写盘，避免中间态覆盖；
- 读取时版本不符走 `migrate()`，最终兜底丢弃回默认预设；`fromJSON` 抛错同样回默认预设；
- 未知面板 id 在套用后 `pruneUnknownPanels()` 关闭，避免开出一堆空面板；
- 默认预设（布局版本 3）：决策台居中，右侧涨停梯队 / 行情 / 信号 / 情报同组标签，交易在下。升级时上一版当前排列收成模板「升级前的布局」，屏幕回到这一屏；顶栏「保存布局」把当前排列存成可切换模板；
- 具名预设 `nt.layout.presets.v1`：可保存 / 套用 / 删除，支持导出与导入 JSON（CommandBar 的「布局预设」菜单）。

浮窗开启（`disableFloatingGroups: false`）。**popout 已启用（P5）**，采用 dockview 的 DOM 迁移模型：

- `window.open('/popout.html')` 打开空白宿主页（多页 Vite 入口，无脚本），主窗口把面板组 DOM 移入并复制全部样式表——同一 JS 上下文，面板内 pinia / WS / ECharts 照常工作；
- Tauri capability 新增 `core:webview:allow-create-webview-window`；
- 白名单 `POPOUT_ALLOWED`（18 个只读/展示面板）：trade（下单）、settings、ops 禁止弹出——`canPopout(id)` 在 `DockHost.popoutPanel` 与 `PanelTab` 的 ⧉ 按钮双重把关；
- 标签页 ⧉ 按钮触发 `workbench.popoutPanel(id)` → `api.addPopoutGroup(panel)`。

## 5. 命令面板与快捷键

`workspace/CommandPalette.vue`：

- `Ctrl+K` 面板态（面板 + 预设 + 命令），`Ctrl+Shift+P` 或输入 `>` 进命令态；
- 打分约 30 行：全等 > 前缀 > 子串（越靠前越高）> 子序列，取前 40；
- `role="listbox"` + `aria-activedescendant`，↑↓ 选择、Enter 执行、Esc 关闭（走 `ui/useOverlay` 的 z 栈与 Esc 链）；
- 命令清单：刷新账户/行情/风控、重连行情通道、切主题、切密度、重置布局、退出登录。

下单/导航热键 `workspace/shortcuts.ts`（P5，WorkbenchView 挂载时启动）：

- 输入态保护：焦点在 `input/textarea/select/contenteditable` 时全部忽略；忽略带 Ctrl/Meta/Alt 的组合，避开 Tauri 全局快捷键（如 Ctrl+Shift+N 唤回）；
- `B` / `S`：开交易面板并预选买/卖（经 `stagePanelParams('trade', {side})`）；
- `Shift+T` 交易 · `Shift+K` 急停确认窗（经 `nt:kill-switch` window 事件桥接 KillSwitchBar）· `Shift+M` 涨停梯队 · `Shift+R` 风控链；
- `1`–`9`：切换当前组内第 N 个标签页（经 DockHost `defineExpose` 的 `getApi()`）。

## 10. 窗口

窗口关闭时缩到托盘，避免盘中误退。系统通知走 `notification` 插件，凭据入系统凭据库（本地会话不伪造账户数字）。

- **popout 窗口（P5）**：面板 ⧉ → `window.open('/popout.html')`，WebView2 侧由 `core:webview:allow-create-webview-window` capability 放行；`web/popout.html` 是多页 Vite 入口（空白宿主页，无脚本），构建产物 `dist/popout.html`；
- **CSP（P5 收紧，P6 验收）**：`tauri.conf.json` 的 `security.csp` 由 `null` 改为白名单——`default-src 'self' tauri: ipc:`；`script-src 'self' tauri: ipc:`（无 unsafe-inline/eval）；`style-src 'self' 'unsafe-inline'`（Vue 运行时注入样式所需）；`img-src 'self' data: blob:`（图表 canvas 截图）；`connect-src 'self' tauri: ipc: http: ws:`——admin 主机地址可在设置页运行时改（任意内网 IP:端口），故 connect-src 放 scheme 源而非固定主机，REST/WS 仍只由 `utils/endpoint` 拼接。

## 12. 决策台「一张票」（优化方案 P3，2026-10-12）

按 `优化实施总体方案.md` §4 的票形状与 §6 的 P3 行落地。纯前端拼接，只用现有信号/候选接口，不新开模型调用，不新建与会话账平行的表——票是读模型，不是第二本账。

- **布局**：决策台主体 = 左栏三列（340px）+ 右栏正文，窄屏（<900px）上下堆叠。左栏：待执行（approved/risk_checking/pending，综合分倒序）、已执行（executing/done/closed，带一句话了结注）、漏选（漏斗字段 + missLabel 一句原因 + 规则分，无模型长文）。被 Rxx 拒绝（rejected/expired/cancelled）不进待执行。
- **票正文顺序**：票头（代码/名称/方向/形成日/综合分或「规则分」）→ 价格块（入场区间、止损、止盈、有效期、请求仓位——来自规则，不来自模型）→ 四维投票（固定四行 技术/消息/资金/外围，中立线 50 与 brain neutralScore 同口径，<50 记反对，缺的维写「—」不跳过；点反对维聚焦该维证据）→ 异议（反对维在前，一票只留一轮，不循环辩论）→ 理由 1–5 条 → 证据编号（沿用 M05：`F:` 因子、`N:` 情报）→ 风控块（请求仓位、允许仓位、规则号、夹掉的部分留在现金）。
- **诚实边界**：没有研判正文写「未调用」或「规则分：模型降级，没有研判正文」，不编造理由；漏选原因只来自漏斗字段；风控参数读不到时允许仓位写空并注明「以风控实检为准」（真正的夹紧发生在下单时）；持仓接口失败与「真的空仓」分开写（`positionsOk`），接口没应答不把账面显示成空仓。
- **降级与高亮**：模型降级的票分数位置标「规则分」；85+ 保留现有高亮；决策台容器不加发光（发光预算只给 AI 高分信号/预警/Kill Switch）。
- **入口与跳转**：CommandBar 权益/盈亏旁「待执行 N」，与左栏同一口径（`isPendingStatus`，30 秒一拍），点击聚焦决策台；点代码进行情面板，点下单进交易面板并带代码/方向/入场价（交易面板在 P4 才拦截）。WS 推送 2 秒节流内更新。
- **实现**：组装纯函数在 `view/decision-desk.ts`（dimVotes / objectionsOf / splitReasons / ticketRisk / buildTickets / buildMissed），视图在 `OverviewView.vue`；测试在 `view/__tests__/decision-desk.test.ts`。
