# M12 桌面客户端 · 设计文档

版本 v0.2。

技术：已有 Vue 3 + Vite + vue-router。桌面壳用 Tauri 2，`frontendDist` 指向 `../dist`。K 线用 lightweight-charts，其余图用 ECharts。这两项是新增前端依赖，只用于图表，不替代自绘面板。

控件皮肤集中在 `web/src/style/controls.css`，由 `global.css` 引入。按钮、输入框、下拉框、表格、滚动条、代码块都在这里。页面只用变体类：`nt-btn-primary`、`nt-btn-ghost`、`nt-btn-danger`、`nt-btn-success`。表格外包一层 `nt-table-wrap`。不要在单个页面里重写这些控件。

目录：

```
web/src/api        按域封装 REST
web/src/ws         连接、订阅、断线补拉
web/src/view       总览、信号、行情、交易、情报、回测、运维、设置
web/src-tauri      托盘、快捷键、系统通知、凭据
```

窗口关闭时缩到托盘，避免盘中误退。

后端地址只配 admin 的 2001 / 2003。不让界面直连 datahub 或 trade。

断线时顶栏固定提示，数字旁显示「截至 HH:mm:ss」。
