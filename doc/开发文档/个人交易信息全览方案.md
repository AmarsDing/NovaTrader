## 1. 结论

代码层面，采集、行情、情报、智脑、选股、风控、模拟盘、通知、驾驶舱都已经有骨架，完成度大多在 85%–90%。作为个人炒股的**当天决策**，现在的信息不够。缺的不是再堆面板，而是三件事同时成立：

1. 盘中价格、日线、新闻真的进库。
2. 本地模型打开，四维评分和情报重评不再停在规则降级。
3. 打开软件第一眼就能看见：今天能不能做、做什么、为什么没选上、哪条链路是空的。

本系统不能承诺「稳稳抓住潜力股」。它能做的是：在两个模板的漏斗里，把够格的少数标的连同价格、止损、证据和漏选原因摆到同一屏，并且在数据缺失时明确说缺失。

## 3. 情报分析够不够深

管道是完整的：去重、归簇、别名关联、12 类规则、重要度、衰减、公告金额抽取、重要度 ≥ 4 或情感突变告警。这是「处理得过来」，还不是「看得透」。

现在的浅，来自四处：

- 模型关着。否定句（例如「不减持」）会判错，设计上靠模型修正，修正没发生。
- 改写稿合不进同一簇。SimHash 只能抓转载和小改。向量归簇留给知识库，嵌入又没接。
- 关联准确率还没做 200 条抽样。词典要有全量证券简称才有意义。
- 桌面情报页以前要手输代码才出时间线，热词和板块是旁边两列，没有接到「今天要做的那几只」上。

够用的深度，对个人超短来说是：一条消息能回答「关于哪只、哪一类事件、有多重要、还剩多少衰减、和今天的候选是不是同一只」。不需要把研报写成研究报告。

## 4. 交易上的专业内容够不够

够的部分已经在规则里，不在界面堆砌里：

- 硬过滤：ST、停牌、上市不足 90 天、昨日成交额低于 5000 万、已在涨停、黑名单。
- 价格：ATR14，入场 ±0.25ATR，止损 2ATR 且不超过 7%，止盈 3ATR，涨跌停夹价。
- 仓位：信号给百分比，股数由账户算，再过风控 R00–R15。
- 交易约束：T+1、费用、涨停不买、跌停不卖、14:50 后不出买点、每天最多 5 个买入、急停停买不停卖。
- 后验：T+1/3/5，漏选原因落在候选表。

不够的部分：

- 模板只有两个。连板加速、烂板、趋势中军不在范围内。加模板之前要用回测校准现在这两个，而不是先加。
- 资金面、席位、竞价在 M02 有计算，决策屏上还没有按「当前这只」摊开。
- 实盘文件单、对账、未知状态不重发，都还没做完。
- 默认参数（0.4/0.6 融合、75 入选、85 高价值）是首版取值，没有 20 个交易日的样本。

## 5. 怎样才叫信息全、传递及时、抓得住

抓得住的定义收窄成：漏斗命中的标的，在有效期 30 分钟内送到眼前，带入场、止损、止盈和证据；没选上的写明原因。除此之外的上涨，系统本来就不接。

要做到这一点，顺序固定：

1. **先有数。** 通达信盘后下载写满 `vipdoc`；配上 Tushare；新闻/公告源能发出 `intel.raw.*`；datahub、market、intel、strategy、brain、trade、notify、admin 都在跑。
2. **再有判断。** 配上 vLLM，打开 `intel.llm.enabled`，晨报和四维不再长期 `ai_degraded`。嵌入服务接上之后，改写稿和案例才有语义。
3. **再有一屏。** 决策台同时放缺口、动作、情报、漏选、持仓。信号和告警走已经常驻的 WebSocket，2 秒内刷新，不当成轮询才知道。
4. **再谈实盘。** 模拟盘连续 20 个交易日，量化终端登录并打开文件单目录。在这之前，界面必须继续拒绝实盘。

## 6. 驾驶舱

一屏，不靠记忆去翻 21 个面板：

```text
┌ 决策台（主）─────────────────────┬ 涨停梯队 ┐
│ 缺口：哪条链路是空的             │ 行情     │ 同一组标签
│ 权益 / 盈亏 / 情绪 / 是否实时    │ 信号     │
│ 今日动作：代码、分数、价、止损   │ 情报     │
│ 晨报一句话 + 热词                ├──────────┘
│ 点一只 → 这条的情报时间线        │
│ 漏选原因                         │
│ 持仓权重 + 板块                  │
├ 交易（下）───────────────────────┘
```

右侧标签保留原来的专业页。决策台只回答「现在」，点代码再进 K 线、点下单再进交易。玻璃和发光仍只给命令栏、弹层、告警和 85 分以上的信号，决策台本身不加发光。

当前排列会自动记住。要留成可切换的模板：顶栏「保存布局」，写名称，再点「保存为模板」。升级默认屏时，上一版排列收在模板「升级前的布局」里，点名称即可套回。
