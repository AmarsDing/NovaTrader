## B5 AH 溢价查询时直抓端点（2026-10-20）

目录册（`M01-数据采集/端点目录.md` v1.5）增补第 3 条：A/H 两地上市配对与溢价。与 B2（落表）/B3（纯计算）都不同型——本片为**查询时直抓**（对等会话裁决取向 (a)）：market 服务在被调用时即时外抓配对与三腿报价并合成，不落库不进调度。参照口径逐行对 vibe-astock（`eastmoney.py:1153-1168` 配对 + `tencent.py:112-143` 报价，「可直接去抄」授权在案）。

**本批硬约束（自钉，对等裁定立档）**：不进计划管线（无采集域、无 worker、无 RawSink）、零新域零表（ent schema 零改动）、cron 零增——全部计算发生在请求路径上，天然幂等无回放体。

**五条护栏（对等裁定，逐条落位）**：
①**端点白名单 + 轻量只读 client**：白名单仅三路（东财 datacenter-web `RPT_F10_BASIC_ORGINFO` / 腾讯 `qt.gtimg.cn` 三符号同批 / 同批内 `whHKDCNY`——FX 与报价同请求零新增源）；显式超时（≤5s）+ 并发上限（信号量 2）；**按需不轮询**；【疑似限流/封禁】(403/429) 与非 2xx → `pair_error`/`source_error` 四态之一并打行首标签；数据面任何缺失经 missing[] 显式，**禁静默回退 0/1.0/均值**；market data 侧自建自含薄 client（Go internal 规则不可跨包引 datahub httpc）。
②**三腿合成逐腿显年龄**：A 现价 / H 现价 / HKDCNY 各带取到时刻回波（`a_time/h_time/fx_time`，实测三腿天然不齐——A 昨收、H 上周五、FX 今晨可同时出现）；任一缺失 → 该腿四态显 + 整体标降级（missing[] 逐项），衍生列（ah_ratio/premium_pct）整体缺省，**禁「看起来完整」的拼图**。
③**配对缺失 = 「无 H 配对」显式**：F10 行无 / `STR_CODEH` 为 null / 非 `.HK` 后缀三态合一判 `no_pair`（实测 000001.SZ 平安银行 = 行在场但 STR_CODEH null，**空数组只是 no_pair 的一种形态**）；缓存存 `(pairing, fetched_at)` 进程内 TTL——正命中 24h（≤交易日级）、负命中 30min；**过期且刷新失败 → `pair_error` 不产溢价数**（对等立档口径「配对未知」，五态中取 pair_error 承载，绝不复用陈旧当真、也绝不把刷新失败谎报成 no_pair）。
④**HKDCNY 不走 pyworker**（护栏 4 的加路分支不触发）：`whHKDCNY` 与 A/H 报价同 GET 第三符号一次取（vibe FX 惯例同）；单源零降级，缺 → missing=["hkdcny"] + 衍生缺省；proto `FxRate` 留独立指针保底口径。
⑤**ent schema 零改动**：本批无表改动预期，落表再 ping 对等。

**数据流（S0–S7，全在 market 包内）**：parseSymbol（v1 只接 A 股）→ biz.AHPremium 编排 → F10 配对（TTL 缓存命中短路；未命中走白名单 client）→ `no_pair` 短路返回（**此时腾讯报价调用计数恒 0，测试钉**）→ 腾讯三符号一次 GET（`q={sh|sz}{a},r_hk{h},whHKDCNY`；**r_hk 不转小写**，大小写敏感实证）→ GBK 解码 + 三 layout 解析（A `20060102150405` Asia/Shanghai；**H `2006/01/02 15:04:05` Asia/Hong_Kong 回退 FixedZone(+8)**——斜杠布局已实测，按 A layout 解析会静默丢 H 腿；FX f[5] 紧凑）→ ahCompute 纯函数（`ah_ratio=round(a/(h×rate),4)`、`premium_pct=round((ratio−1)×100,2)`，正=A 贵；T2 折价防恒正盲区不钳 0）→ Reply。

**F10 口径**：URL 宿主机理与 datahub emDC 同（datacenter-web `/api/data/v1/get`，同宿主同参数形态）；业务码语义复制 `dc()` 分家——`success:false code:9201` 或空列表 = 确实没有 → no_pair；`code:9501` = 报表轮换 → `pair_error` 不自动换名；其他非 0 码 / 成功码畸形 data = 请求坏了 → `pair_error`。列取 `SECUCODE/STR_CODEH/STR_NAMEA/SECURITY_NAME_ABBR/STR_NAMEH`（STR_NAMEA 与 SECURITY_NAME_ABBR 兜底）。
**活源验收闸（动 data 层前的强制第一步，2026-10-20 已执行、全绿）**：curl 实证 ①`601939.SH` 行在场 STR_CODEH="00939.HK" 带后缀；②`000001.SZ` 行在场 STR_CODEH/STR_NAMEH 双 null → no_pair 判据三态合一成立；③腾讯三符号同取三行全回（A 11.57@20261019161436 紧凑 / H 9.865@`2026/10/16 16:08:22` 斜杠 / FX 0.8510@20261020065912），GBK 解码正常——三个必要坑（GBK、H 斜杠时间、r_hk 大小写）全部实证为真。验收记录随实施记录归档，活源探测不进 CI。

**proto 五态**（`GetAHPremium`，`GET /v1/market/ah-premium`）：`ok / no_pair / missing / pair_error / source_error` + reason；配对事实列（a_code/a_market/a_name/h_code/h_name/a_traded）非 optional 照常回波；三腿 optional（a_price/h_price/hkdcny）+ 衍生 optional（ah_ratio/premium_pct）指针直传；`pair_source="eastmoney_f10"`、`quote_source="tencent"` 恒标签、as_of 恒有、missing[] 逐项。明确不做：同日收盘对齐 / 停牌剔除（a_traded=false 照算透出）/ 复权 / 股本非 1:1 矫正 / side=H 入参。

**纪律（没取到≠0）**：任一脚缺失只进 missing[]，衍生列整体缺省；`pair_error` 与 `source_error` 同样回波配对事实列（能查到什么给什么）；停牌照算但 a_traded=false 显式；前端消费侧衍生列 `number|null` 兜底、status≠ok 显原因不画假溢价。

## B3 筹码分布 CYQ 纯计算端点（2026-10-20）

目录册（`M01-数据采集/端点目录.md` v1.4）增补第 2 条：筹码分布按原判「纯计算型零新源，输入齐备，先手工端点」落地。与 B2 内部计算落表不同，本片**纯计算不落库**——无新表、无调度、无配置变更；算法归 `pkg/market` 纯函数包，聚合归 market biz，读出口随 market proto。

- **输入**：`market_data` 1d OHLCV（含 `adj_factor`）× `stock_basic.float_share`（流通股本）。turn = V/float_share×100 百分数。
- **口径**：CYQ 换手衰减模型（`pkg/market/chip.go`，逐行对齐 vibe-astock 公开口径）——成本网格 `[lo−pad, hi+pad]`（pad=振幅×2%，零振幅退 lo×2% 最小 0.01；网格默认 300，合法域 50..2000）；每日三角权重 `triWeights(grid, low, high, hlc3)`（峰在均价，窄振幅映射最近格点不丢换手）；滚动 `chips = chips×(1−t) + w×t`，t=clamp(turn/100×decay, 0,1)；首日 = 期初全部流通筹码。前复权 = `价×adj/窗口末根adj`（通达信默认口径），复权不涉换手率。
- **产出**：获利比例（现价以下筹码占比，现价格点按半步容差）、加权平均成本、90%/70% 成本区间（P05/P15/P85/P95 线性插值）、集中度 (P95−P05)/(P95+P05)、筹码峰价、现价；事实列 `days_used/cum_turnover_pct/window_start/window_end` 照常回波。
- **纪律（没取到≠0）**：四态 status——`ok` / `missing`（无券或窗口空）/ `not_meaningful`（窗口行数 < minPoints=20；float_share≤0 无法算换手；**adj_factor 缺失不可复权，§4.4 禁以 0/1 冒充因子**，任一根或末根 ≤0 整体 not_meaningful）/ `error`（请求非法，例如 grid_size 越域 50..2000 → service 侧 MARKET_INVALID 400）。B3 不新增回写路径，衍生列 proto `optional double`，status≠ok 全缺省不产假数，消费侧按 `number | null` 兜底、显「数据不足/缺失」不画 0 分布。
- **读出口**：`GET /v1/market/chip-distribution`（symbol 必传；as_of 空 = 最近已收盘交易日；days ≤0 默认 250、>400 截 400；grid_size ≤0 默认 300）。

## 1. 输入（M01 写，M02 读）

Redis Hash `snap:latest`，field 为 `600519.SH`，value 为 JSON：

```json
{"symbol":"600519.SH","time":"2026-10-09T09:31:03+08:00","as_of":"2026-10-09T09:31:04+08:00",
 "source":"tdx_local","stale":false,"pre_close":1500.0,"open":1501.0,"high":1510.0,"low":1498.0,
 "last":1505.0,"volume":123400,"amount":185600000.0,
 "bid":[[1504.99,300],[1504.98,100]],"ask":[[1505.0,200]]}
```

- `time` 是交易所行情时间，`as_of` 是写入时间。`volume`（股）、`amount`（元）是当日累计值。
- 每写完一轮，datahub 发普通 NATS `market.snapshot`，payload 为 `SnapshotMeta` 六键（`as_of/source/count/latency_ms/seq/stale`，合同见 M01 设计文档 §7.3）。本服务收到就读一轮；收不到时每 3 秒自己读一次。
- `stale=true` 或 `now - as_of > stale_after`（默认 10 秒）的快照不参与计算，计数进 `/metrics`，查询结果带 `stale`。

日线、复权因子、资金、龙虎榜、板块成分、外围行情由 M01 直接写第 3 节对应表。

## 2. 1 分钟 K 线

- 标签为开始时间。上午 09:30～11:29，下午 13:00～14:59，共 240 根。
- 09:30 那根包含集合竞价成交，开盘价取快照 `open`。11:30:xx 的快照归 11:29；15:00 之后的快照（收盘集合竞价）归 14:59。
- 量额由累计值相减。3 秒快照会漏掉瞬时高低点，用快照里的日内 `high`/`low` 变化补：日内最高价被刷新时，当前分钟的最高价取新值。
- 某分钟没有新成交时补一根平线（开高低收 = 上一根收盘，量 0），与通达信一致。
- 分钟结束 5 秒后封口，批量 upsert 到 `market_data(freq=1m)`。
- 15:05 用当日分钟线合成日线写入 `market_data(freq=1d, source=market_agg)`；若 M01 已写入当日日线则不覆盖。M01 夜间写入的 Tushare 日线覆盖本服务的合成值。

| `overseas_quote` | M01 | code, trade_date | 外围收盘与涨跌幅 |
| `overseas_mapping` | 人工 | asset_code, sector_code | 外围标的 → 板块，带权重 |

全部写入走 ent upsert（`OnConflict`），重复执行不增行。

## 4. 指标

### 4.1 公式（通达信口径，默认参数）

| 指标 | 公式 | 输出键 |
|------|------|--------|
| MA | `MA(C,N)`，N=5/10/20/60 | `ma5` … `ma60` |
| EMA | `EMA(C,N)`，α=2/(N+1)，首值为第一根收盘 | `ema12`、`ema26` |
| MACD(12,26,9) | `DIF=EMA12−EMA26`，`DEA=EMA(DIF,9)`，`MACD=2×(DIF−DEA)` | `dif`、`dea`、`macd` |
| RSI | `SMA(MAX(C−LC,0),N,1)/SMA(ABS(C−LC),N,1)×100`，N=6/12/24，`SMA(X,N,M)=(M×X+(N−M)×Y')/N` | `rsi6` … |
| ATR(14) | `TR=MAX(H−L,|LC−H|,|LC−L|)`，`ATR=MA(TR,14)` | `atr14` |
| BOLL(20,2) | `MID=MA(C,20)`，`UB/LB=MID±2×STD(C,20)`，STD 为样本标准差 | `boll_mid`、`boll_up`、`boll_low` |
| 量比 | 见需求 2 节 | `vol_ratio` |
| 换手 | `V/流通股本×100` | `turnover` |
| 振幅 | `(H−L)/LC×100` | `amplitude` |
| VWAP | 日线 `amount/volume`；盘中为累计值 | `vwap` |
| 涨跌幅 | `(C−LC)/LC×100` | `pct_chg` |

窗口不足时该键不输出，不补 0。

### 4.2 复权与时点

- 库里存不复权价和后复权因子 `adj_factor`。后复权价 = 价 × `adj_factor`。
- 指标在后复权序列上递推。MA、EMA、MACD、ATR、BOLL 是线性的，前复权值 = 后复权值 ÷ 当日 `adj_factor`；RSI、量比、振幅、涨跌幅与缩放无关。除权日不用重算历史，也不会出现「今天看昨天的指标变了」。
- 盘中用「已收盘日线状态 + 当日临时 K 线」预览，不改状态，O(1) 完成。
- 启动和每天 08:40 预热：每只股票载入最近 250 根日线。EMA 类指标与通达信（从上市首日起算）的残差约 1e-4 量级，属于可解释误差。

### 4.3 落库时点

`stock_factor` 只在这些时刻落库：09:25 竞价（`auction`）、10:00 / 11:31 / 14:30（`intraday`，11:31 等 11:29 那根封口）、收盘（`close`，`as_of` = 当日 15:00）、19:30 资金（`capital`）。时刻可配置。分钟级回测由 1 分钟 K 线重算，不读这张表。

### 4.4 缺失语义（没取到≠0，P3-10 收编）

本节收编本文档原有的两条散规，并对齐全仓数据纪律（`doc/开发文档/0.数据纪律.md`、M01 设计文档 N3-01）：

- **窗口不足不补 0**（原 §4.1 尾注，现保留）：指标窗口不足时该键不输出。下游消费 `stock_factor` 时，缺键 = 无法判定，必须按缺失处理，禁止按 0 参与计算（如量比缺 → 不输出而不是 0，0 量比是真实「零成交」，语义不同）。
- **过期不参算**（原 §1 尾注，现保留）：`stale=true` 或超 `stale_after` 的快照不参与计算，查询结果带 `stale`。过期是 `WhyStale` 缺失，不是有效值。
- **取数失败不是 0**：因子计算所需的价、量、前收、流通股本任一源字段缺失时，该因子键不输出；整域取数失败由 M01 侧 `data_quality_issue` 留痕，并在 API 以缺失态返回。函数级结果用 `dataformat.Result[T]` 表达（见总则 §2）。
- **复权因子**：`adj_factor` 缺失时历史价不可复权——相关派生量（后复权价序列）为缺失态，禁止以 0 或 1 冒充后递推。M01 已在采集侧保证缺因子不写库。

## 5. 涨停生态

- 涨停价 = `ashare.Limit(pre_close, ratio)`，整数分四舍五入。上市不满 5 个交易日不判断。
- 封板：`last == 涨停价` 且卖一为空。从未封到封记首次 / 最后封板时间；从封到开记一次炸板。
- 封单额 = 买一量 × 涨停价，取最近一次封板时的值。
- 收盘：仍封住为 `SEALED`，否则曾触板为 `BROKEN`。连板数 = 前一交易日 `SEALED` 行的连板数 + 1。
- 跌停对称处理，`direction=DOWN`。
- 盘后补数可用日线：收盘 = 涨停价为 `SEALED`，最高 = 涨停价且收盘低于涨停价为 `BROKEN`，没有封板时间。

## 6. 情绪阶段

从上到下第一个满足的为当前阶段：

| 阶段 | 默认条件 | 评分系数（M06） | 仓位系数（M08） |
|------|----------|-----------------|-----------------|
| ICE 冰点 | 涨停 < 30 且跌停 ≥ 30；或赚钱效应 ≤ −3% | 0.80 | 0.3 |
| FADE 退潮 | 炸板率 ≥ 40%；或上一阶段为 WARM/HOT 且赚钱效应 < 0 | 0.85 | 0.3 |
| HOT 高潮 | 涨停 ≥ 80、炸板率 < 25%、高度 ≥ 5、赚钱效应 ≥ 3% | 1.05 | 0.8 |
| WARM 升温 | 涨停 ≥ 50、炸板率 < 35%、赚钱效应 > 0 | 1.00 | 1.0 |
| RECOVER 修复 | 以上都不满足 | 0.95 | 0.6 |

仓位系数与 M08 自己的阶段系数表一致（HOT 低于 WARM：高潮次日分歧风险大），M08 以它自己的表为准，这里只是随 `market.state` 一起带出的参考值。

阈值和系数以 JSON 存在 `strategy_config` 键 `market.sentiment.rules`，改动走 `pkg/params` 生成新版本，可回滚。读不到时用上表默认值。「上一阶段」取前一交易日收盘阶段。

风险等级（随 `market.state` 给 M08，从上到下第一个满足的）：

| 等级 | 默认条件 |
|------|----------|
| 3 | 上证指数（`000001.SH`）日内跌幅 ≤ −3%，或 5 分钟跌幅 ≤ −1.5% |
| 2 | 日内 ≤ −2%，或 5 分钟 ≤ −1%，或阶段为 ICE |
| 1 | 日内 ≤ −1%，或炸板率 ≥ 40%，或阶段为 FADE |
| 0 | 其他 |

整体过期：还没有任何行情，或过期快照超过有行情股票的 5%，情绪截面和 `market.state` 标 `stale=true`；指数快照过期也标。个别股票偶发过期只影响它自己的因子。

## 7. 板块、资金、外围、竞价

- 板块热度（成员 ≥ 5 只才排名）：`heat = 1.0×平均涨幅% + 1.0×涨停数 + 5×上涨占比 + 0.5×外围冲击`，权重在 `market.sector.weights` 可改。
- 龙头：板块内当日涨停股中连板最高者；同高取首次封板更早者；再同取封单额大者。没有涨停股时取涨幅最高且成交额 ≥ 1 亿元者。
- 资金因子：`main_net_ratio = 主力净额/成交额`，`main_net_5d`（近 5 日主力净额和）。龙虎榜：`lhb_net`、`lhb_inst_net`（机构席位净额）、`lhb_quant_net`、`lhb_north_net`（北向席位净额）、`lhb_hot_buyers`（游资席位净买入个数）。席位标签来自 `seat_tag`，未标记的计入 `lhb_net` 但不计入分类。
- 外围冲击（08:50 计算）：板块冲击 = Σ 权重 × 映射标的涨跌幅%，只取 A 股上一交易日之后、今日 09:00 之前的最新外围收盘。写 `sector_heat`，`as_of` = 08:50。
- 服务启动时补默认行，已有行不覆盖，人工改过的标签和权重保留：

| 表 | 默认 |
|----|------|
| `seat_tag` | `机构专用` = INSTITUTION，`沪股通专用` / `深股通专用` = NORTH。营业部席位不预置 |
| `overseas_mapping` | `CL` → `T010301` 石油开采，权重 1；`CL` → `T010302` 石油加工，权重 0.5 |

板块代码用通达信行业（`tdxhy.cfg` 第三列）。M01 若改成东财 `BK` 代码，这两行要改成对应代码。黄金、半导体、航空等着 M01 写出对应行情和涨跌幅后再加。
- 竞价因子（09:25 后第一轮快照）：`auction_pct`、`auction_amount`、`auction_vol_ratio`（竞价量 ÷ 前 5 日每分钟均量）、`auction_turnover`、`auction_amount_prev`（竞价额 ÷ 昨日成交额 ×100）、`auction_unmatched`（09:20～09:25 最后一笔快照的买一量 − 卖一量，股）、`auction_limit_up`（开盘即涨停为 1）。

## 9. 性能

每轮快照：聚合、涨停判断、5000 只指标预览、情绪截面全部在内存完成。要求 5000 只单轮 ≤ 30 秒。实测（开发机）：`BenchmarkProcess5000` 约 10 ms/轮，含建引擎的 `TestFullMarketRefreshWithin30s` 约 21 ms。封口分钟线在同一轮里批量 upsert（每批 1000 行）。写库耗时还没有在 DGX 上实测。
