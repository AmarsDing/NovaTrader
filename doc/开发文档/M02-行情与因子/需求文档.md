## 2. 口径（评审时补齐）

| 项 | 口径 |
|----|------|
| 涨停 | 收盘价等于涨停价，且收盘时卖一为空 |
| 曾涨停 / 炸板 | 盘中最高价触及涨停价，但收盘未封住 |
| 炸板率 | 炸板数 ÷（涨停数 + 炸板数） |
| 连板数 | 昨日连板数 + 1；昨日未涨停则为 1 |
| 连板高度 | 当日涨停股的最大连板数 |
| 赚钱效应 | 昨日涨停股（剔除今日一字板）今日平均涨幅，单位 % |
| 涨跌家数 | 剔除停牌股；涨跌幅为 0 的计平盘 |
| 成交额 | 全部 A 股成交额合计，单位元 |
| 量比 | 日线：当日量 ÷ 前 5 日均量。盘中：累计量 ÷（前 5 日每分钟均量 × 已开盘分钟数） |
| 换手 | 成交量 ÷ 流通股本 × 100 |
| 主板 ST 涨跌幅 | 2026-07-06 起 10%，之前 5%（沪深交易规则 2026 年修订）。创业板、科创板 ST 20%，北交所 30% |

## 3. 验收

- 5000 只股票指标全量刷新 ≤ 30 秒（基准测试）。
- 指标单测按通达信公式逐项核对；本机 `vipdoc` 下载后用 10 只样本与通达信界面数值对照，差异写进开发进度。
- 涨跌停价在 1.00～1000.00 元全价位与整数分精确算法一致。
- 同一交易日重复跑收盘任务，结果行数不变（upsert）。
- 回测按时刻读因子时，拿不到 `as_of` 晚于该时刻的数据。
