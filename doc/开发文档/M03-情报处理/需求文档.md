# M03 情报处理 · 需求文档

| 模块 | M03，服务 `intel` | 版本 v0.3（2026-10-08 评审后补口径） |

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-03-01 | 新闻、快讯、公告、研报、舆情统一入库。入口为 M01 发布的 `intel.raw.<kind>`，另提供 HTTP 手动录入 | P0 |
| FR-03-02 | 哈希去重 + 近似去重，合并成事件簇。同一簇只评一次大模型、只告警一次 | P0 |
| FR-03-03 | 关联股票和概念，带置信度。低于阈值（默认 0.6）的不关联 | P0 |
| FR-03-04 | 事件分类：业绩、增持、减持、回购、处罚、政策、重组、合同、解禁、停复牌、退市风险、其他 | P0 |
| FR-03-05 | 情感分存在 [-1, 1]，另有重要度 0–5 和半衰期（分钟） | P0 |
| FR-03-06 | 高重要度或情绪突变，1 分钟内发 `intel.alert` | P0 |
| FR-03-07 | 公告、研报抽取金额、比例、日期，记录在正文中的位置，能回到原文 | P1 |
| FR-03-08 | 热词：近 N 小时被提及最多、且比上一窗口增长最快的个股、概念、事件类型 | P1 |
| FR-03-09 | 个股消息时间线，附当前有效情感 | P0 |
| FR-03-10 | 广告和低质来源过滤；被过滤的保留记录，不评分、不发事件 | P2 |
| FR-03-11 | 模型网关不可用时用规则打分兜底，结果标 `degraded`，不阻塞入库和告警 | P0 |

验收：

- 入库到评分完成（`received_at` → `scored_at`）P95 ≤ 1 分钟；源头发布到入库的延迟归 M01。
- 规则路径单条处理 ≤ 100 毫秒（不含模型调用）。
- 抽样关联准确率 ≥ 90%：用 `stock_basic` 全量别名词典，对 200 条人工标注样本统计。样本集在 M01 新闻源接通后整理。
