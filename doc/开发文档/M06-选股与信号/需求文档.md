# M06 选股与信号 · 需求文档

| 模块 | M06，服务 `strategy` | 版本 v0.3 |

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-06-01 | 盘前池、盘中池、持仓池、黑名单 | P0 |
| FR-06-02 | 硬过滤 → 规则打分 → 只把前 30 名送给 AI → 融合出信号 | P0 |
| FR-06-03 | 综合分 ≥75 入选，≥85 标高价值。规则分与 AI 分的权重可配置（默认 0.4 / 0.6）。模型不可用时只用规则分并标 `ai_degraded` | P0 |
| FR-06-04 | 策略可插拔。第一版两个模板已经定下：模板一「首板/弱转强」，模板二「强势回踩」。规则写在设计文档第 4 节 | P0 |
| FR-06-05 | 信号含标的、方向、入场区间、止损、止盈、仓位、有效期、四维分、证据 | P0 |
| FR-06-06 | 止损 = 入场 − ATR×2，止盈 = 入场 + ATR×3，最大止损幅度 7%，时间止损按模板（2 / 5 个交易日）。由代码计算 | P0 |
| FR-06-07 | 状态：待处理、风控中、通过/拒绝、执行中、完成、过期、取消。迁移规则见设计文档第 7 节 | P0 |
| FR-06-08 | 同股同方向冷却；已持仓不重复开仓 | P0 |
| FR-06-09 | 全市场扫描 ≤ 3 分钟；盘中以事件触发为主 | P0 |
| FR-06-10 | 策略版本可切换、可回滚 | P1 |
| FR-06-11 | 记录 T+1/T+3/T+5 实际表现 | P0 |
| FR-06-12 | 记录「符合规则但没入选」的后续表现 | P1 |
| FR-06-13 | 卖出信号：止盈、止损、时间到、情绪退潮、突发利空 | P0 |
| FR-06-14 | 收到 Kill Switch 后停止出买入信号，卖出信号照常；重启后状态不丢 | P0 |

默认模板：**首板/弱转强**、**强势回踩**。2026-10-08 按超短线定位确认，不再悬空。接口仍允许以后换模板。

验收：

- 两个模板、硬过滤、融合、价格计算、状态机、冷却都有单元测试，覆盖主板 10%、创业板 20%、主板 ST（2026-07-06 前 5%，之后 10%）的涨跌停夹价。
- 用一组构造好的全市场快照跑一次漏斗，产出的信号字段齐全，`signal_events` 和 outbox 各有对应记录。
- 模型不可用时仍能出信号，且全部标 `ai_degraded`。
