# 驾驶舱信息面板专业评审

| 项 | 内容 |
|----|------|
| 日期 | 2026-10-12 |
| 对象 | 21 个 dockview 面板 + CommandBar / StatusBar / AlertCenter 三处 chrome |
| 方法 | 通读 `web/src/view/*`、`web/src/panels/*`、`web/src/api/*`、`web/src/utils/format.ts`、`web/src/ws/hub.ts`、workspace chrome，对照 `1.视觉需求.md`、`个人交易信息全览方案.md`、`优化实施总体方案.md` |
| 立场 | 个人超短（首板弱转强、强势回踩）盘中第一视角：能不能做、做什么、为什么没选上、哪条链路是空的 |

## 1. 总体结论

四问四答：

| 问题 | 结论 |
|------|------|
| UI 是否专业 | **是。** 视觉纪律全仓最好的一类：红涨绿跌集中判定、发光预算只给 ≥85 信号/预警/Kill、玻璃只在三处 chrome、空态诚实（「不把空数据当成平静」）。 |
| 信息展示是否专业 | **七成。** 格式化、缺口驱动、风控链可视化是专业的；但有 3 处确定性显示 bug、两套术语、接口字段被归一化层丢弃，专业度漏在细节上。 |
| 信息面是否全 | **不够。** 缺：信号有效期/状态/建议仓位（接口有、前端丢了）、当日盈亏只在顶栏、持仓浮盈、指数条、个股报价条、一键全撤、今日买入计数、昨日涨停表现。资金/席位/竞价是 P6，不催。 |
| 展示形式是否合理 | **基本合理。** 表格/卡片/时间线分工清楚；主要问题是决策台持仓用 chips 太简、四维雷达与列表重复、部分面板只首拉不订阅推送。 |

一句话：**骨架和纪律已经专业，现在漏的是「接口里有、界面上没有」的那一层，以及几处口径 bug。** 修复不需要新面板，也不需要等 P1/P2 的数据。

## 2. 立得住的专业点（保持，不回退）

1. 决策台缺口驱动：`decision-desk.ts` 的 `buildGaps` 把 Kill、数据源、快照、实时性、晨报、模型降级、模拟天数排成阻断/警告两级，点击跳对应面板。这是全仓最专业的信息设计。
2. 诚实空态：「没有读到的项保持为『—』」「链路齐」反向文案，符合总体方案第 3 节边界 1。
3. 交易面板：代码正则、100 股整手、可买量预估、LIVE 先确认、仅非终态可撤、viewer 角色锁。
4. 涨停梯队：封板/炸板分列、按连板高度分档、情绪五阶段带 stale 标注、market 主题推送 15 秒节流。
5. WS 中枢：seq 断线续传、主题引用计数、去重回放（`ws/hub.ts`）。
6. AlertCenter：极端预警全屏锁 + 声音 + 队列，Esc 不静默关。符合发光预算第三处。
7. `format.ts` 集中涨跌判定、错误信息人话化（`messageOf`）。

## 4. 逐面板评审

### 4.1 决策台（OverviewView）— 评级：良，差一层信号细节

现在显示：缺口、权益/浮动盈亏/情绪/系统四卡、今日动作（代码/方向/分/入场区间/止损）、晨报+热词、焦点情报、漏选、持仓 chips+全市场板块图。

问题：
1. 四张卡里「权益/浮动盈亏」与 CommandBar 顶栏完全重复，而**当日盈亏（dayPnl）只在顶栏有**。决策台应该把重复的两卡换成「当日盈亏 + 可用资金使用率」这类桌面级数字。
2. 今日动作行没有时间、没有有效期、没有状态、没有建议仓位（B2 的直接后果）。9:45 的信号和 14:49 的信号长得一样。卖出信号和买入信号混排。
3. 持仓用 chips（代码/股数/权重），没有成本、现价、浮动盈亏。超短第一眼看持仓就是看浮盈。
4. 「板块涨跌」画的是全市场板块，标题区却叫「持仓」，语义错位；持仓所属板块才是这一格该回答的。
5. 热词、pulse（「刚到：信号 xxx」）不可点击——信息到了但进不去。
6. 缺口不覆盖交易通道（broker-gw 文件单）和通知通道；P11 之前至少要有一句话占位。

### 4.2 信号中枢（SignalView）— 评级：中，信息最不完整的核心面板

问题：
1. B2 + B3：字段丢、不订阅。补字段后每张卡还应显示：信号时间、有效期倒计时（过 30 分钟置灰标「已过期」）、建议仓位%、ATR、状态机（risk_checking/approved/…）。
2. 无过滤：全部信号一锅端，没有 买/卖、有效/已过期/已平仓、模板 三组基本过滤；无排序控制。
3. 四维雷达图和旁边的四维数字列表信息完全重复，雷达在降级时四根 50 分毫无信息量。建议：降级时雷达换「规则分」标记，理由区上移。
4. 证据是纯文本列表，没有来源类别（F: 因子 / N: 情报 的编号约定已在 M05，界面没用）。

### 4.3 交易（TradeView）— 评级：良，缺盘中要素

1. 持仓表只有 代码/数量/可卖/成本/现价 —— **没有市值、浮动盈亏、盈亏%**（avgCost、lastPrice 都在，纯前端可算）。
2. 委托表没有时间列；成交表没有费用、没有当日合计（成交额/费用/净盈亏）。
3. 没有「今日买入 x/5」「今日拦截 n 次」计数（RiskState.buysToday 有数据，没人显示）。
4. LIVE 在账户下拉里永远可选；未满 20 交易日的拒绝只在后端发生。UI 应该禁用并写原因（准入状态 evolution 面板已有接口）。
5. 无一键全撤。超短尾盘一键全撤是刚需，后端有 cancelOrder 逐条接口即可前端批量。
6. 持仓代码不可点击进行情（决策台可以，这里不行，不一致）。
7. 下单表单没有现价参考和涨跌停夹价提示——填价时唯一参照要去行情面板看。

### 4.4 行情（MarketView）— 评级：中，超短视角最不达标

1. **没有报价条**：一只股票的最新价、涨跌幅、量比、换手、振幅、封单额——超短看盘第一行信息，整屏缺失。bars 最后一根可以凑出简版。
2. 周期只有日线和 1 分钟：没有 5/15/30/60 分钟、没有分时、没有竞价。
3. `getFactors(kind=capital/auction/intraday)` 这个 API **全前端零调用**（P6 的范畴，但连个「未调用」占位都没有，与总体方案 P5 岗位表冲突——那里要求资金岗标「未调用」）。
4. 完全手动刷新，不订阅 market 主题；盘中这张图是死的。
5. 消息侧栏无重要度、无类别徽章、不可点进情报面板。
6. 指标只有 MACD/RSI；K 线消息标记取标题前 8 字，密集时糊在图上。

### 4.5 情报（IntelView）— 评级：中

1. 时间线仍要手输代码（全览方案 §3 已点名）；决策台的焦点联动只解决了决策台内部。
2. 热词、板块龙头、外围脉冲都不可点击——看到热词进不了对应时间线。
3. `IntelItem.importance` 字段存在但全前端不显示；重要度 ≥4 的告警在通知里出现，在情报流里反而没有标记。
4. 综合情感是个裸数字（如 0.62），没有量纲说明（区间？中轴？）。

### 4.6 涨停梯队（limit-ladder）— 评级：良，梯队数据还差三个维度

1. B9（名称=代码）、B11（赚钱效应口径）。
2. 梯队内按封单额排序；打板视角更关心**封板时间先后**（谁带的头）。
3. 「封单额」卡实际是「最高连板首位的封单额」，标签名不副实；全市场封单总额才是情绪指标。
4. 缺：昨日涨停今日表现（溢价率）、连板晋级率、涨停的板块分布。这三个是超短情绪复盘的核心，后端目前也没有，属 R3。
   - **2026-10-13 更新**：前两项后端已补——`GET /v1/market/ladder`（连板晋级率，1进2/2进3/3进4+）与 `GET /v1/market/limit-premium`（昨日涨停今日溢价，开盘/收盘双口径，`limit_premium` 快照表 + 09:27/16:45 任务）。两者已接入监控驾驶舱的扫描牌（见 M02/M12 开发进度）；本面板（limit-ladder）接上它们即可补齐「溢价率/晋级率」两栏。涨停的板块分布仍未做。
5. 跌停只有一行代码流，没有封单和开板信息。

### 4.7 晨报（morning-briefing）— 评级：良

条目用 kind 冒充时间轴的 time 字段，没有真实时间也没有重要度；外围隔夜数据只在正文里，没有结构化小块。可接受，不优先。

### 4.8 模型链路（brain-monitor）+ 模型统计（model-stats）— 评级：中，职责重叠

1. 两个面板共享同一张 tier 表，21 面板里最明显的一对重复。建议：model-stats 并入 brain-monitor（或 model-stats 改成只留 4 张汇总卡的常驻窄条）。
2. B6（reasons/risks 丢弃）、B8（kvCache、单位）。
3. 推理进度 `AnalyzeProgress.done/total` 有数据，界面只渲染文字，没有进度条。
4. P5 的「七岗位值班表」会把 brain-monitor 重做，本评审不重复设计；但 B6/B8 修起来不等 P5。

### 4.9 自选扫描（watchlist）— 评级：弱

1. B5：扫描当场丢弃漏斗数据。
2. 已登记的候选池没有回显（刷新面板即丢失，只剩 expiresAt）。
3. 无扫描历史（traceId 显示一次就没了）。

### 4.10 股池黑名单（pool-manager）— 评级：中

B1（收益率 100 倍）、B7（漏选英文）。另：无交易日列（多日候选混在一起）、无 refPrice、黑名单只能加/删**看不到当前名单**、行不可点进行情。

### 4.11 风控链（risk-chain）/ 风控日报（risk-report）— 评级：良

1. B12（预检只有 SIM）。
2. 当前风控参数（R 系列阈值：每日 5 单、2ATR、7% 等）界面无处可见——RiskState.params 有数据没人显示。「风控夹了多少」是总体方案§4 票上的必备格。
3. 今日已买入计数、marketBreaker 状态不进头部。
4. 日报只有当日静态表，无拦截率趋势（reject_rate 预警已经在 AlertCenter 有源，顺藤可补）。

### 4.12 影子进化（evolution）— 评级：良

四 tab 完整，审批闭环。缺：提案没有参数 diff（改了什么、改前改后值看不见，审批是在盲签）；B11 口径；影子 vs 实盘没有曲线对比。

### 4.13 通知中心（notify-center）— 评级：中

`read` 字段全链路无人用（无未读、无标记已读）；级别筛选用原生 `<select>`（全仓唯一不用 NtSelect 的地方）；无按 kind 过滤；无「跳到来源面板」；与 StatusBar 无未读角标联动。

### 4.14 知识库（kb-search）— 评级：中

嵌入未接，检索浅（方案已声明）。分数只作为 tag 文本。可用，不优先。

### 4.15 数据源（datasource-health）— 评级：良

状态灯口径清晰（enabled+lastAt+熔断）。缺：无手动触发采集、无熔断重置按钮——看着源红了只能干等；质量报告无缺失明细钻取。

### 4.16 运维（OpsView）— 评级：中

资源行是纯字符串，无阈值无图形（显存/磁盘）；只手动刷新。大屏级监控在 `/monitor`（canvas），运维面板保持简表可以接受，但应有「打开监控大屏」入口——目前 `/monitor` 从驾驶舱没有任何链接能到达。

### 4.17 回测（BacktestView）— 评级：中（P7 已规划，不重复）

成绩条六格、基准曲线、费用口径、运行记录都在 P7。本评审只补一条：任务运行中没有进度显示也不会自动刷新，「排队/运行中」状态停到手动刷新。

### 4.18 审计（audit-trail）— 评级：良

过滤、留痕、角色徽章齐全。缺时间范围和操作人过滤（低优先）。

### 4.19 三处 chrome

- CommandBar：权益+当日盈亏+布局预设+用户——专业。**当日盈亏在这里**（dayPnl 优先，浮动兜底）。
- StatusBar：链路/模式/Kill/实时性/订阅主题/时段钟——专业。缺：SIM/LIVE 账本标识、未读通知角标。
- AlertCenter：见 §2.6，全仓标杆。

## 6. 修改方案

与 `优化实施总体方案.md` 的关系：P0–P11 照走，本文不另立阶段号。下面 R0/R1 是 P 计划之外、不等数据不等模型的修补；R2 点名已被 P 计划覆盖的项；R3 需要新后端数据。

### R0 立即修（纯前端，证据确凿，建议一次做完）

1. pool-manager 的 T+1/T+3/T+5 改 `ratioPct`；顺手全仓核对 `pctText` 的每一处调用（profitEffect、shadow、avgPct），确认后端口径后统一：后端一律返回比率、前端一律 `ratioPct`，`pctText` 改名 `ppText` 限定「百分点口径」场景（B1/B11）。
