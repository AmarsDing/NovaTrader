## 部署（三台机器）

| 节点 | 跑什么 |
|------|--------|
| DGX Spark（Linux） | PostgreSQL、Redis、NATS、Go 微服务、vLLM、pyworker（AkShare / 通达信 TCP 备源） |
| Windows 交易机 | 通达信金融终端（行情）、东方财富量化终端（文件单）、`broker-gw` |
| 用户桌面 | Tauri 客户端（可与交易机同机，生产建议分开） |
