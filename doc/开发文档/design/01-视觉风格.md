# 01 · 视觉风格

> 唯一视觉基准：[Aether V2 演示](assets/aether-v2-2026-10-30/index.html)。本文所有规则均从该案例与 [tokens.css](../../../web/src/theme/tokens.css) 实测提取；取值表见 [03-设计令牌.md](03-设计令牌.md)。

## 1. 设计方向（为什么这样定）

**深海控制台 / 星舰座舱**：蓝黑结构底 + 分层玻璃舱面 + 冰青仪器读出。

- **深色底是为了长时间盯盘**：行情/订单界面是持续注视场景，深底降低整体亮度疲劳；同时提供完整亮主题（`data-theme='light'`），不是反色而是独立校准的一套值。
- **冰青（#45e0ff）作唯一操作强调色**：高亮冷色在深蓝底上对比充足，且与金融语义色（涨红/跌绿/警黄/险红）在色相上拉开距离，操作与状态永不混淆。电蓝（#769dff）仅作辅助与渐变端点。
- **红涨绿跌是 A 股约定，不可调换**；色觉安全档（`data-colorvision='safe'`）切换为"暖涨冷跌"（朱红/钴蓝），靠明度与黄蓝轴保持可辨。
- **AI 产物有专属语义色（紫 #c792ea）**：AI 生成/研判内容与用户操作、行情状态三者在视觉上可区分，不借 accent 顶替。

## 2. 色彩使用规则

| 规则 | 执行 |
|---|---|
| 一个颜色来源 | 只取 tokens.css 的 `--nt-*`；案例里的 `--nt-at-*`/`--gx-*` 是演示局部参数，迁移时收敛到主题，禁止在业务代码复制固定色值 |
| 背景四层 | `--nt-bg-0/1/2/3` = 结构底 → 内容层 → 悬浮层 → 选中层；禁止发明第五层 |
| 文字四级 | `--nt-text-1/2/3` 承担正文/次级/辅助；`--nt-text-0`（最亮档）**每个面板最多一组主指标**（现价、权益），禁用于段落与表格正文 |
| 强调色用途 | accent 只用于：当前对象、可操作控件、焦点、细边与局部反光；不用于大面积铺色 |
| 语义色不可交换 | 涨/跌经既有 format 函数与 up/down 类输出；warn/danger/success/info 按真实状态判断，禁止按"好看"互换 |
| 对比度 | 正文合成背景对比度 ≥4.5:1；暗/亮/色觉安全/节能四档都要过 |
| 禁装饰性文字效果 | 正文不用模糊字、渐变字、常驻文字光晕 |

## 3. 材质：分层玻璃

| 表面 | 规则 |
|---|---|
| 空间底 | 同一片低对比青蓝光场 + 静态精密网格（`--nt-space-bg`）；背景不穿透重要正文形成干扰 |
| 玻璃壳 | 半透明蓝灰 + 细边 + 顶部反光 + 有限阴影（`--nt-glass-*`），用于主对象、工具坞、配置外壳、浮层 |
| 真实数据背板 | 行情、订单、K线、证据长文用**近不透明**稳定底色（`--nt-data-*` ≈ .98），玻璃只留在壳层——长时间阅读区不做半透明 |
| 边光 | 沿控件**真实轮廓**绘制；圆形/胶囊/圆角卡片不得出现外接矩形发光 |
| 流光 | 活动主对象允许一层 16s 慢流光，opacity ≤0.24；普通入口仅 hover/focus 单次掠光；数字/表格/图表正文不加流光 |
| 节能档 | `data-visual-quality='eco'` 下去掉 blur/glow/sheen，保留结构、文字、告警 |

## 4. 排版与尺寸

- 字体：界面用系统中文栈（`--nt-font-sans`）；**价格、数量、比例、时间、URL、技术值一律等宽字体 + tabular-nums**（`--nt-font-mono`）。
- 字号阶梯（7 档，禁止中间发明档位）：hero 24 / num-lg 17 / title 15 / panel 13 / body 12.5 / caption 11.5 / micro 10.5px；compact 密度按 12/12.5 等比缩小。
- 中文功能名优先；按钮用具体动词（"审阅变更""保存此分类"），确认操作写清后果。
- 缺失数据显示 `—` 及原因；遮蔽显示 `•••`；两者不可混用。
- 间隔节奏 4/8/12/16/20/24px，28/32px 仅用于大对象、分区与页边距。
- 控件高度：标准 42px / 紧凑 36px；触屏有效目标 ≥44px，触屏文本输入字号 16px（防 iOS 自动缩放）。
- 圆角三档：6 / 8 / 12px；演示中的大对象 28px、内容面 22px 为场景参数，业务组件收敛到三档。胶囊用 999px。同心几何按真实半径对齐。

## 5. 布局模式

- 工作区最大宽 1480px，页面最小可用宽 320px。
- 顶部：品牌/工作面 + 命令入口 + 主题/动效开关；主体 = 一个主对象 + 成组辅助对象；工具坞在正文之后的独立布局行，**不得覆盖字段、操作条或回执**。
- 概览：一个主入口（约 62% 面积）+ 2–3 个辅助区；grid-area 明确，DOM 顺序与视觉顺序一致，不用 dense 填洞。
- 管理页：筛选条 → 列表/主体 → 详情抽屉；抽屉宽走 360/480/640 阶梯，超过走模态。
- 行情/订单/证据类界面：对齐数据列 + 稳定背板 + 状态/时间证据，**不得改造成入口卡墙**。

## 6. 响应式

- 工作区断点：≥1200px 加强 / 1099 / 799 / 559 / 359。
- 对象视图：≥1100px 主辅并列；800–1099px 缩减图形与空白；<800px 单列；<560px 辅助对象/快捷项单列。
- 配置容器按**容器宽度**响应：≥1440 侧置回执 / 1100–1439 主列+回执摘要 / 720–1099 折叠目录 / <720 单列；字段内宽 <560px 时字段单列。

## 7. 动效原则

- 状态与焦点先更新，动画随后反馈；动画可中断、可跳过，迟到回调不得覆盖新状态。
- 按压 120–160ms；提示 120–180ms；选中/描线/滑片 160–260ms；dock 透镜 360ms；对象展开 340ms；顶级工作面 140–180ms 轻淡入。
- 系统"减少动态"优先（`data-motion='reduced'` 时过渡归零）；后台/失焦/离屏停止装饰运动；销毁时释放监听、计时器、观察器。

## 8. 与 V1（stellar-glass）的差异说明

V1 的侧栏布局、36px 控件、16/12/8 圆角、720ms 长动效已被 V2 取代，仅作历史参考，不得再从 V1 抄样式。
