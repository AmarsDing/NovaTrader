# 04 · 落地检查清单

> 前端评审/提交前逐项核对。任一项不通过 = 不合并。跨项目通用项见 `teamwork/design/FRONTEND-UI-GUIDE.md` 第 7 节。

## A. 令牌与颜色

- [ ] 无裸色值：全文搜索新增 CSS/样式，无 `#xxx`、`rgb()`、`hsl()` 字面量（tokens.css 本身除外）
- [ ] 状态色全部走语义 token（up/down/warn/danger/success/info/ai），无按装饰需要互换
- [ ] 未新增第五层背景、第四档圆角、第八档字号
- [ ] accent 仅用于操作/焦点/当前对象，未大面积铺色

## B. 材质与文字

- [ ] 数据密集区（行情/订单/K线/证据长文）使用 `--nt-data-*` 近不透明背板，玻璃 blur 只在壳层
- [ ] 边光沿真实轮廓，圆形/胶囊无外接矩形发光
- [ ] 数字/时间/URL 用等宽字体 + tabular-nums
- [ ] `--nt-text-0` 每面板 ≤1 组主指标；正文对比度 ≥4.5:1
- [ ] 正文无渐变字、模糊字、常驻文字光晕

## C. 组件状态

- [ ] 每个新/改控件覆盖 default/hover/focus-visible/pressed/selected/disabled/loading/error 适用状态
- [ ] 复合输入外壳独占 focus-within 轮廓，内部 input 无矩形 outline
- [ ] 错误说明始终可见；loading 由真实请求驱动，失败有原因+重试
- [ ] 触控目标 ≥44px；必要功能无需 hover/长按/手势即可达

## D. 状态文案与证据

- [ ] 缺失显示 `—` 及原因，遮蔽显示 `•••`，两者未混用
- [ ] "已保存/已生效/在线/实时"等文案均可追溯到真实回执；无证据不显示"全部就绪"
- [ ] 敏感项仅显示"保留/替换/清除"，未渲染 before/after 真实值

## E. 响应式与动效

- [ ] 在 320px 最小宽度可用；配置容器按 1440/1100/720/字段560 断点表现正确
- [ ] 动效时长在本规范档位内（按压 120–160 / 选中 160–260 / 透镜 360 / 展开 340ms）
- [ ] `data-motion='reduced'` 与 `data-visual-quality='eco'` 下装饰运动停止、功能完整
- [ ] 销毁时释放监听、计时器、观察器；迟到回调不覆盖新状态

## F. 无障碍

- [ ] 焦点环可见（2px accent + 4px offset），Tab 顺序与视觉顺序一致
- [ ] 状态播报用 `aria-live`；错误用 `role="alert"`
- [ ] 弹层 Esc 关闭并回焦；菜单先消费 Esc 再退出外层

## G. NovaTrader 专项

- [ ] 未引入第三方组件库（R-UI-12），新控件基于 Nt* 基础件
- [ ] 未在业务页面复制 `--nt-at-*`/`--gx-*` 演示参数与固定色值
- [ ] 暗/亮/色觉安全/紧凑四档均走查
