# 02 · 组件规范

> 组件形态以 [Aether V2 演示](assets/aether-v2-2026-10-30/index.html) 的控件实验室（`#lab`）为可视基准；本文是开发合同。NovaTrader 使用自研 `Nt*` 基础件（禁引第三方组件库）；Quasar 项目的映射见第 6 节。

## 1. 通用状态合同（每个控件必须覆盖）

每个交互控件必须定义以下适用状态，不允许"只有一张好看的静态图"：

`default / hover / focus-visible / pressed / selected / disabled / loading / error`

- 焦点：`outline: 2px solid var(--nt-accent); outline-offset: 4px`；**复合输入由外壳独占 focus-within 轮廓**，内部 input 不再画矩形 outline。
- disabled：`cursor: not-allowed` + 降透明度，功能不消失、原因可感知（只读角色在按钮旁显示原因）。
- loading/成功/进度由真实请求或事件驱动；失败必须给出原因 + 重试/取消/回滚路径；忙碌状态防重入并保留焦点。
- 必要功能不得只能由 hover、长按或手势触达；IME 组合完成后再过滤与提交。
- 触控目标 ≥44px；按压反馈 120–160ms，点击目标与文字位置在按压中保持稳定。

## 2. 基础组件合同

### 按钮（NtButton）
- 三档语义：主（accent 实底 + `--nt-on-accent` 文字）、次（玻璃面 + accent 描边）、危险（danger 语义，仅破坏性操作）。
- 文案为具体动词，确认型按钮写清后果；禁用自制第四档"好看按钮"。

### 图标按钮（NtIconButton）
- 40×40 圆形/圆角，图标统一 NtIcon 轮廓语法（stroke 1.6、圆角线帽）；`aria-pressed` 表达开关态，选中态 = accent 色 + accent-border 描边。

### 输入（NtInput 系）
- 排版固定为 标签 → 当前值/控件 → 单位/说明/错误；错误说明**始终可见**，不靠 toast 一闪而过。
- text/select：选项来自数据源/schema，禁止拿中文展示文案当 value。
- int/number：数值等宽、单位可见；整数/范围错误内联提示；无证据不新增 min/max 业务约束。
- secret：已设置徽章 + 密码替换框 + 显式清除；留空=保留，清除=待保存；不提供读取旧明文。
- json/宽文本：跨列、等宽、可展开；解析错误就地定位；未知键保留。

### 选择控件
- 区分四种：固定单值 / 检索单值 / 分组多值 / 动作菜单。
- 自定义弹层统一：顶层定位、碰撞翻转、Esc/外点关闭、关闭后回焦；菜单先消费 Esc，再退出外层视图。

### 开关（bool）
- 右侧必须有"启用/关闭"或明确用途文字；点击只改草稿状态，不得偷偷即刻提交服务参数。

### 面板 / 对象壳
- 玻璃壳 + `--nt-radius-l`；壳内数据区用近不透明 `--nt-data-*` 背板；面板标题用 fs-panel，页头标题用 fs-title。

### 表格 / 数据列
- 行高 `--nt-row-h`（26px，compact 22px），单元格 padding `--nt-cell-pad`。
- 数值列等宽字体右对齐，文本列左对齐；涨/跌只经 up/down 语义类输出；空单元格显示 `—`。
- 不给表格正文加玻璃模糊、渐变字或流光。

### 状态胶囊 / 标签（NtTag）
- 胶囊半径 999px，padding 4px 10px，fs-caption；状态色必须走语义 token（success/warn/danger/info/ai），禁止裸色。
- 在线、实时、保存成功等文案必须能追溯到真实证据；无证据不显示健康百分比或"全部就绪"。

### 浮层体系
- 模态：`--nt-scrim` 遮罩 + 玻璃壳 + `--nt-shadow-depth`；非模态浮层（命令面板等）用 `--nt-scrim-light`。
- 详情抽屉：360/480/640 宽度阶梯，超过走模态；抽屉不覆盖操作条与回执。
- 命令面板：胶囊触发器（最小高 48px）+ kbd 提示；检索不过滤密钥值。

### 空态 / 错误态 / 缺证据
- 空态 = 图标 + 一句话说明 + 一个主操作；不得只留空白面板。
- 错误态 = 原因 + 重试/取消；`role="alert"` 让读屏即时播报。
- 缺证据一律显示 `— / 未返回 / 待核验` 及原因；禁止用默认值伪装成读取到的运行值。

## 3. 动效参数（组件级）

| 动作 | 参数 |
|---|---|
| 按压 / 颜色 / 提示 | 120–160ms / 120–180ms，ease `cubic-bezier(.4,0,.2,1)`（演示壳用 `cubic-bezier(.22,.8,.22,1)`） |
| 选中 / 描线 / 滑片 | 160–260ms |
| 工具坞透镜 | 360ms 缓出；标签与焦点立即更新，不等待透镜 |
| 对象展开 | 340ms 轮廓连续变换；快速切换可打断 |
| 慢流光 | 16s 线性循环，opacity ≤0.24，仅活动主对象 |
| 减少动态 / 节能 | 过渡归零，装饰运动停止 |

## 4. 精修组件（GX-01~24）执行摘要

24 项星舰精修组件（卫星菜单、翻面卡、跃迁、滑轨、持按确认等）是**优先实现参考**，完整逐项合同见 `archive/前端UI-README-2026-11-02.md` 第 5 节。执行口径：

1. 同一类控件共用 token 与 Nt 基础件，不为单个精修组件发明新色/新圆角/新阴影。
2. 特效按各自合同触发，不全场同时循环；组件特效不得干扰数字与表格阅读。
3. 3802 项 Galaxy 库仅用于寻找技法，逐项保留原作与主题对照，不直接搬配色。

## 5. 文案与证据

- 状态文案分级：`cache_loaded` 只能称"配置缓存已加载"，`applied` 按真实 scope 称"已安装到运行态"；都不代表外部 API 已连通。
- 汇总口径不足时直接显示"加载证据待核验"，禁止合并成"全部已生效"。
- 保存流程：预览（差异/影响/目标服务）→ 确认保存 → 服务端返回新 revision 后才显示"已保存#N" → 独立展示加载回执。

## 6. Quasar 项目映射（HotCraftFlow / aranea-agents）

> NovaTrader 不用 Quasar；本节是跨项目落地约定，详见 `teamwork/design/FRONTEND-UI-GUIDE.md`。

| 本规范 | Quasar 落地 |
|---|---|
| NtButton 主/次/危险 | `q-btn`：`color` 不取 Quasar 品牌色，用 CSS 变量覆盖；unelevated/outline + `--nt-*` |
| NtInput | `q-input` dense + standout 关闭，外壳 focus-within 独占轮廓 |
| 面板/卡片 | `q-card` 去 Material 阴影，用 `--nt-shadow-depth` 与玻璃面 |
| 表格 | `q-table` dense，行高/单元格 padding 用 `--nt-row-h`/`--nt-cell-pad` 覆盖 |
| 状态胶囊 | `q-badge`/`q-chip` 仅作容器，颜色一律语义 token |
| 浮层 | `q-dialog`/`q-menu` 遮罩与圆角用 `--nt-scrim`/`--nt-radius-*` 覆盖 |
