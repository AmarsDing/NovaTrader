```bash
  up -d --force-recreate app web

# 7.3 数据回滚（仅在迁移/写入导致数据损坏时；先停 app，避免写入竞争）

  < /mnt/exdata/novatrader/backup/<BK>/novatrader.dump
docker compose -f compose/base.compose.yml -f compose/app.compose.yml --env-file env/.env up -d app
```

回滚边界：
- ent 迁移**只追加不删列**，代码回滚后新增列/索引会保留（对旧版本无害）；新增表同理。
- **无 down migration**，结构级回退只能靠 Step 2 的 `pg_dump` 还原。
- Redis 缓存键与 NATS JetStream 不做回滚（幂等/可重建），不属回滚范围。
